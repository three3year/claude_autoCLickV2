# 分岔-传递线索

[← 總覽](總覽.md)

## 這段做什麼

- 分岔（只有一個分支：找到第一步那張才往下做）：
  - 找圖點擊「传递线索」，偏移 -3,-12，點到下一步的圖出現（逾時 3s→跳過）〔忙碌檢查〕
  - 找圖點擊「快捷传递重复线索」，偏移 +66,+0（逾時 15s→跳出區段）
  - 等待 0.8 秒
  - 找圖點擊「传递关闭」，偏移 +1,-1，點到目標圖消失（逾時 10s→跳出區段）

## 為什麼這樣做

- 傳遞線索 → 快捷傳遞重複線索 → 關閉；傳遞線索 3 秒內沒找到就整段跳過。
- 傳遞線索勾忙碌檢查：前面剛收完、置入完線索，遊戲常還在提交。
