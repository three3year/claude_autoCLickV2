## 設計原則：正確優先，其次越快越好

- **等畫面，不死等**：轉場一律交給下一步的找圖去輪詢，畫面出現就馬上繼續。輪詢間隔 0.3 秒。
- **只在必要的地方固定等待**：只有「下一個畫面同一位置也看得到同一張圖」時才固定等待，否則會在轉場還沒完成時誤點。
  例如連按兩次返回，中間等 1 秒。
- **可有可無的步驟，逾時短**：例如每日線索、領取、快速置入、商品等，畫面已經穩定時不在就是不在，只等 1.5–3 秒。
- **捲動**（沿用舊手動腳本的精華）：先定位右上「非工作區」分頁，從它出發垂直拖動，拖到終點按住 0.5 秒再放開，止住清單慣性。

## 流程內容

1. **登入彈窗**：每輪同時找「圓形叉叉」和「獲得物資」，有就點掉；5 秒內都沒有就結束。
   公告會在前一個彈窗關掉後約 4 秒自己跳出，所以這裡要等 5 秒。
2. **待辦**：
   - 鈴鐺 → 可收穫 / 訂單交付 / 幹員信賴三個同時找，有就點，沒有 3 秒內結束。
     點掉一個，其他的會往左移，所以每次重新找。
   - 點空白處離開待辦。位置相對左上的返回箭頭計算，因為右上會被收取提示蓋住。
3. **製造站**：
   - 以「進駐總覽」為原點點**第三排中間**那張製造站（同晚班）→ 生產面板 → 無人機加速 → 最多 → 確定 → 收取（3 秒內沒有就跳過）。
   - 返回 ×2 → 等「進駐總覽」出現（同時當作拖動的起點）。
4. **會客室**：
   - 往左拖 → 會客室（點到線索面板出現為止）→ 線索面板。
   - 線索交流彈窗（有才關）→ 每日線索 → 領取 → 快速置入（**只認橘色**，灰色＝線索已滿，不按）。
   - 解鎖線索（**只認可按的顏色**）：有點到才等 2 秒，讓線索板自己關掉 → 重開線索面板。
   - 接收線索 → 全部收取 → 點面板外關掉（10/07 晚加，見最上面那節）。
   - 傳遞線索 → 快速傳遞 → 關閉 → 返回 ×2。
5. **進駐總覽**：製造站 1、製造站 2、貿易站 1、辦公室換班。每站：
   - 先捲到該站在畫面中段，找該類別第一列的列名（比色、由上到下第 1 個、只看畫面上 2/3），再在它上方確認類別標題，
     兩個都對才點 ⇌；製造站 2 是往下一列（+196）。辦公室只有一列，找列名（比色）就點。
     任一個找不到就跳過那一站，不會點到別的列。每下 ⇌ 後等忙碌指示消失。
   - 之後 → 非工作區 → 幹員休息。
6. **好友**：導航 → 好友 → 好友列表（比色，不會點到旁邊的分頁）→ 訪問基建（清單最上面那個）→ 訪問下位 ×10。
   每次點完等按鈕消失（轉場開始），下一輪再等按鈕出現；實測約 2.3 秒一位。
7. **信用交易所**：
   - 導航 → 採購中心 → 信用交易所（比色）→ 收取信用。
   - **找到就買**（2026-10-07 起）：重複區段 ×10 包一個 23 分支的分岔，每輪看畫面上有哪些白名單商品，
     買優先順序最高的那件（同種好幾格時買由上到下第 1 個）；**已售罄的不算**。
     畫面上沒有白名單商品、買不起、獲得物資等不到，就結束購買。優先順序與細節見最上面 10-07 那一節。
8. **公開招募**：導航 → 公開招募。
