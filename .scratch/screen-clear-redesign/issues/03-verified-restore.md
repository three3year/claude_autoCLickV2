# 03 — 清場驗證式還原

**What to build:** 拾取(框選/點選/拉線)結束後,被清場隱藏的視窗**每一次**都確實回到畫面上——完成與取消(Esc)一樣。清場離場改為驗證式:照「自己隱藏的清單」逐窗還原,以 map 事件確認每個視窗真的畫出來(逾時重試),每個視窗都 lift(root 先、對話框後),全部確認可見後才交還 grab、最後才銷毀 overlay(「還原全程在覆蓋層後面、一次揭示」的既有拍板保留)。進出場、每窗驗證結果與重試數寫入檔案日誌。「壞一次就一直壞」隨清單制根除;執行流程迷你視窗的刻意顯隱不受影響。

**Blocked by:** 01(日誌)、02(狀態機)

**Status:** resolved

- [x] 框選完成與取消後,編輯對話框與主視窗每次都回到畫面且 Z 序正確
- [x] 還原對象由清單決定,不再以 wm state 猜測;某窗還原失敗不影響下一次清場
- [x] 每窗 deiconify 後以 map 事件確認可見,逾時重試;zoomed 依快照還原
- [x] overlay 於全部視窗確認可見、grab 交還之後才銷毀
- [x] 清場進出場、驗證重試、跳過(已銷毀)都寫入日誌

- [x] 清場對外介面(context manager、可巢狀)不變,呼叫端不需修改
