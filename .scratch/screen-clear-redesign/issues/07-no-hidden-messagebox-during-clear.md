# 07 — 清場中不彈隱形對話框

**What to build:** click/drag 拾取算不出基準(如沒設搜尋範圍)時的提示訊息,使用者每次都看得見。現行提示在清場期間以已隱藏的對話框為 parent 彈出,可能整個看不見卻在等確認、體感卡死。改為清場結束(視窗還原)後再彈,或以當下可見的視窗為 parent。

**Blocked by:** 03(清場還原時序)

**Status:** resolved

- [x] click/drag 拾取的提示訊息在任何時序下都可見、可關閉
- [x] 提示關閉後拾取流程的後續行為(重試/取消)不變
- [x] 清場期間不再有任何以隱藏視窗為 parent 的 messagebox(全面清查拾取路徑)
- [x] 既有 pytest 回歸網全綠
