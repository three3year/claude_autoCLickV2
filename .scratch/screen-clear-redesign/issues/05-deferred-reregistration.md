# 05 — 存圖後重登錄延後到視窗可見

**What to build:** 框選存新範本圖後,使用者先看到對話框回來,整庫重登錄(reload_profile+refresh_templates,卡主執行緒數秒)才接著跑——「視窗消失」與「程式短暫卡住」兩種感受分開。重登錄改排入「清場還原完成、視窗確認可見」之後的 after() 佇列;延後期間新範本尚未登錄進引擎,期間觸發的引擎查詢(比對測試等)必須先等重登錄完成,不得對新範本名 KeyError。

**Blocked by:** 03(「還原完成」的掛載點)
