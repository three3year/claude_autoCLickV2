# 03 — 視窗先開+引擎背景載入+就緒 gating

**What to build:** 主視窗建好立即顯示並可操作,驗證模型(本票階段含整庫
登錄)改由背景執行緒載入;「視窗可操作」與「引擎就緒」自此是兩個時間點。
狀態列顯示「引擎載入中…/就緒」;引擎就緒前所有辨識類操作——執行流程、
測試選取、F12、比對測試、即時找圖、校準、範本登錄——一律 modal 對話框
提示並拒絕,使用者稍後自行重試(不排隊、不置灰)。背景載入失敗維持現
行為語意:modal 警告後降級粗篩模式。編輯流程、範本管理等不需辨識的操作
完全不受影響。就緒 gating 決策收成純邏輯,UI 只是薄執行層(0003 前例)。
