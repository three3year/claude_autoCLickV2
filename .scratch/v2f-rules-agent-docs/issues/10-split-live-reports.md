# 10 — 四份在用流程的交付報告拆檔

**What to build:** 四份在用流程（`%USERPROFILE%\AutoClick\` 下的早_簡中、早_繁中、晚_簡中、晚_繁中）的單檔 `交付報告.md`，改成 `交付報告/`。

- **結構**：跟工具產出的結構與檔名規則相同：總覽加每個頂層區段一份。
- **內容**：只寫現況；對照現在的 `flow.yaml`，把過期內容標出來。
- **舊檔**：原樣搬成 `交付報告/舊紀錄.md`，總覽註明「歷史，平常不必讀」。
- **不動** `flow.yaml`。

見 spec「四份在用流程的報告拆檔」與「需要你決定的」第二題。

**Blocked by:** 06 — 交付報告改成資料夾（工具端）

**Status:** ready-for-agent

- [ ] 區段切法與檔名用 06 的同一個函式（一次性腳本放 `.scratch`，不進 tools）
- [ ] 每份區段報告：這段做什麼、為什麼這樣做、已知風險、待重拍與待確認；用內容指稱步驟，不寫編號
- [ ] 報告提到、但流程裡已經不存在的範本、步驟、做法，標成過期
- [ ] 舊 `交付報告.md` 搬成 `交付報告/舊紀錄.md`，內容逐位元不變
- [ ] 四份 `flow.yaml` 與 `templates/` 逐位元不變；檢查指令四份都沒有錯誤
- [ ] 請使用者看過其中一份（建議早_簡中），沒意見
