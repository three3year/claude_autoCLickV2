# 05 — 忙碌檢查、校準對必填、不唯一標待重拍

**What to build:**

- **忙碌檢查**：計畫寫了 `busy_check: true` 的步驟，流程裡就勾著；工具不自己判斷要不要勾。自我驗證兩向只報告：勾了但之後影格沒看到忙碌指示、沒勾但之後影格看到了。
- **寫檔前報錯**：勾了 `busy_check` 卻沒設 `busy`、新流程沒寫校準對、影格上量不到主校準對，都在寫檔前報錯，不產出跑不動的流程。
- **不唯一**：範本在影格上不唯一時標待重拍，流程照寫，不自動縮框。

見 spec「忙碌檢查與校準對」「自我驗證與待重拍」、04 規則 5–9。
