# 07 — 補充插入 `insert`（同倍率）

**What to build:** 使用者只錄一小段影片，agent 寫一份補充計畫，跑 `insert <計畫> <流程資料夾>`，就把量好的步驟插進既有流程的指定位置。

- **插入點**：用 `after: N`／`into: N` 指定，加上 `expect`（第 N 步的開頭鍵＋範本）核對。
- **原點**：
  - 插入段第一個座標點擊／拖曳之前，段內必須有找圖。
  - 插入後，插入點後面的舊步驟在重新找圖之前用到的原點來源不得改變。
- **範本**：
  - 步驟可引用既有範本（不重裁，照跑拾取檢查）。
  - 新範本撞名報錯。
  - 新範本跟既有範本幾乎一樣時，建議改用既有的。
- **沿用**：校準對與忙碌指示沿用既有流程。
- **寫回**：
  - 經 app 讀檔 → 記憶體插入 → 經 app 寫檔。
  - 任何報錯都在寫檔前；失敗時既有資料夾一個位元都不變。
  - 不備份。
- **報告**：插入處那份與總覽更新。

本票只處理影片與流程同尺度（倍率 1）。見 spec「補充插入」、13 規則 6–10。
