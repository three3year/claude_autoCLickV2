# 04 — 組裝產固定矩形

**What to build:** 影片轉出來的流程，每個找圖步驟、確認圖、`wait_gone` 目標與忙碌指示都自帶固定矩形，不必事後手框。

- 框＝這一步自己那一幀上實際挑中的框，每邊外推範本寬高的 50%（相對座標基準點、流程尺度）。
- 計畫宣告了捲動軸的步驟，那一軸拉到影片兩端。
- 超出畫面就裁到影片邊；貼邊那一側不算失敗。
- 同區段有拖曳、找圖又沒宣告捲動軸的，列進報告的待確認。

見 spec「固定矩形」、04 規則 1–4。

**Blocked by:** 03 — 轉換計畫改新鍵

**Status:** ready-for-agent

- [ ] 經 app 讀回：每個找圖目標的 `within`＝挑中框外推 50%，中心不變
- [ ] 同一張範本在不同步驟各用各的幀算，不取聯集
- [ ] 宣告 `scroll: vertical|horizontal` 的步驟，該軸到影片兩端，另一軸照 50%
- [ ] 框超出畫面時裁到影片邊；裁過的那一側不觸發待重拍
- [ ] 確認圖、`wait_gone`、忙碌指示套同一套規則
- [ ] 「有拖曳但沒宣告捲動軸」的找圖步驟出現在結果的待確認清單
- [ ] 矩形餘裕檢查照跑；沒過＝工具錯誤
