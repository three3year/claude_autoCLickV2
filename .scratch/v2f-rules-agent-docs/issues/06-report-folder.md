# 06 — 交付報告改成資料夾（工具端）

**What to build:** `assemble` 產出的流程資料夾裡是 `交付報告/`：`總覽.md` 加每個頂層區段一份。之後的 agent 只改某一段時，只讀那一份。

- **檔名**：取區段開頭找圖的範本名（例 `分岔-公告关闭.md`、`重複-标题_制造站.md`）。
- **零散步驟**：區段之間連續的零散頂層步驟併成一份，用那段第一個找圖的範本命名（例 `步驟-基建入口.md`）。
- **撞名**：加序號。
- **指稱步驟**：用內容指稱，不寫步驟編號。

見 spec「交付報告」與「需要你決定的」第一題。

**Blocked by:** 04 — 組裝產固定矩形；05 — 忙碌檢查、校準對必填、不唯一標待重拍
