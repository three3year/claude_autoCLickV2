# 08 — 補充的影片倍率

**What to build:** 補充用的影片不必跟既有流程同尺度。

- **量倍率**：`insert` 在所需影格上先找既有流程的主校準對、再找備用對，量出影片倍率 r 與座標基準點在影格上的位置。
- **換算**：r 在支援倍率範圍內都收。影格整張縮放 1/r、以基準點對齊後，座標、拖曳距離、固定矩形、新範本與拾取檢查都在流程尺度下做。
- **報錯**：
  - r 超出範圍報錯。
  - 影片裡完全量不到校準對時，改在計畫的 `scale_image`（使用者給的同取景圖片）上量；沒有圖片就報錯，不收手打的倍率。

見 spec「補充插入」的影片倍率與換算、13 規則 4–5。

**Blocked by:** 07 — 補充插入 `insert`（同倍率）

**Status:** ready-for-agent

- [ ] 合成影片用 ×0.9（或其他非 1 倍率）產生：插入後座標、拖曳距離、固定矩形、新範本尺寸都是流程尺度（在容許值內）
- [ ] 主校準對量不到、備用對量得到時，用備用對
- [ ] r 超出支援倍率範圍時報錯
- [ ] 影片量不到時用 `scale_image`；沒有圖片報錯；計畫直接寫倍率數值也報錯
- [ ] 總覽記下這次補充的影片倍率與來源影片
- [ ] 每種報錯之後，既有資料夾逐位元不變
