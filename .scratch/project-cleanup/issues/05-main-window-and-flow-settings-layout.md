# 主視窗與流程設定對話框版面（原型）

Type: prototype
Status: open

## Question

瘦身後主視窗與「流程設定…」對話框長什麼樣？用 `/prototype` 做可以點的 Tk 假畫面（或 ASCII 版面圖）讓使用者反應。
已定的內容（ADR 0014、grilling.md §5）：
- 主視窗：開檔／新流程／存檔、框搜尋範圍（含顯示現狀與清除）、執行模式＋次數、▶執行／■停止、測試選取、
  步驟清單（拖曳排序、雙擊編輯、Delete、Ctrl+C/V、摺疊）＋選取列的 ✎✕、範本面板（清單、截圖新增、重截、重新命名、刪除、
  未引用標記、縮圖）、執行紀錄＋清除、「流程設定…」鈕、狀態列（待機／執行中、F12 提示）。
- 流程設定對話框：校準對、備用校準對、忙碌指示三列，各有現狀文字＋「設定…」「清除」「測試」。
- 拿掉：profile、開啟資料夾選單、▲▼、⧉、範本複製／上傳／比對測試／重新整理、校準鈕、避開游標、啟動延遲、兩個毫秒值。

要決定的：
- 兩欄還是三欄；範本面板與執行紀錄上下還是並排；工具列一列還是兩列。
- 「新增步驟」的入口（選單鈕保留十項 → 現在是 find／click／drag／wait＋五個標記，九項）。
- 執行中的迷你視窗保留不動？
- 未存檔狀態怎麼顯示（標題 `*`）。

產出：使用者點頭的版面圖連結進本票。
