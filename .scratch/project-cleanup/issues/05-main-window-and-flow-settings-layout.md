# 主視窗與流程設定對話框版面（原型）

Type: prototype
Status: resolved

## Question

瘦身後主視窗與「流程設定…」對話框長什麼樣？用 `/prototype` 做可以點的 Tk 假畫面（或 ASCII 版面圖）讓使用者反應。
已定的內容（ADR 0014、grilling.md §5）：
- 主視窗：開檔／新流程／存檔、框搜尋範圍（含顯示現狀與清除）、執行模式＋次數、▶執行／■停止、測試選取、
  步驟清單（拖曳排序、雙擊編輯、Delete、Ctrl+C/V、摺疊）＋選取列的 ✎✕、範本面板（清單、截圖新增、重截、重新命名、刪除、
  未引用標記、縮圖）、執行紀錄＋清除、「流程設定…」鈕、狀態列（待機／執行中、F12 提示）。
- 流程設定對話框：校準對、備用校準對、忙碌指示三列，各有現狀文字＋「設定…」「清除」「測試」。
- 拿掉：profile、開啟資料夾選單、▲▼、⧉、範本複製／上傳／比對測試／重新整理、校準鈕、避開游標、啟動延遲、兩個毫秒值。

要決定的：
- 兩欄還是三欄；範本面板與執行紀錄上下還是並排；工具列一列還是兩列。
- 「新增步驟」的入口（選單鈕保留十項 → 現在是 find／click／drag／wait＋五個標記，九項）。
- 執行中的迷你視窗保留不動？
- 未存檔狀態怎麼顯示（標題 `*`）。

產出：使用者點頭的版面圖連結進本票。

## Answer

（2026-10-12 原型定案：使用者附圖指定配置，原型版面 D 實作後點頭）

**主視窗**（兩列工具列＋兩欄）：

| 位置 | 內容 |
|------|------|
| 第一列 左 | 新流程／開檔／存檔 ｜ 搜尋範圍 ⓘ＋現狀（全螢幕／限定 (x, y, w, h)）＋框選／清除 |
| 第一列 右 | 「校準對 ✓／✗　忙碌指示 ✓／—」摘要＋「流程設定…」鈕 |
| 第二列 左 | 模式（執行次數／直到停止）＋次數 ｜ 大字狀態（待機／引擎載入中…／執行中 第 n/N 輪）｜ ▶ 開始執行／■ 停止 |
| 第二列 右 | F12 = 急停 |
| 主區 左（寬） | 執行步驟：標題旁「測試選取」靠左；新增步驟鈕靠右＝找圖／點擊／拖曳／等待＋「區段 ▾」（重複開始／結束、分岔開始／或／結束）；寬度不夠時整排收成一顆「＋ 新增 ▾」列出全部九項。清單：拖曳排序、雙擊編輯、Delete、Ctrl+C/V、摺疊；選取列只剩 ✎ ✕ |
| 主區 右上 | 本流程的範本：「截圖新增」；清單（沒被引用的灰字＋「（未引用）」）＋縮圖；重截／重新命名／刪除 |
| 主區 右下 | 執行紀錄＋清除 |

- 不另設狀態列（狀態移到第二列）；舊版第三列（校準鈕、校準對說明、忙碌指示…）整列拿掉，收進流程設定對話框。
- **未存檔**：只在視窗標題前加 `*`（`*早_簡中 — AutoClick`）。
- **執行中的迷你視窗**：不動。

**流程設定對話框**：三列——校準對、備用校準對、忙碌指示；每列＝名稱 ⓘ＋現狀文字（`A × B（基準 N px）`／`沒有（不能執行）`／範本名／`不設`）＋設定…／清除／測試；底部「關閉」。每列沒有常駐說明字。

**說明文字規則**（使用者 10/12；主視窗、流程設定、步驟編輯器等所有對話框一體適用）：
- 一般說明先簡化成「使用時才需要的資料」，放進欄位標題旁的 ⓘ，滑鼠移上去才顯示；不常駐。
- ⚠ 警告（依目前設定才出現、要使用者動手的）縮成一行常駐顯示，例：「⚠ 下一步要是找圖步驟」。
- 標題類文字也要精簡。

原型：`prototype/main-layout` 分支的 `app/prototype_main_layout.py`（版面 D＝定案；A/B/C 是落選的對照）。
階段 3 的驗收「元件數對照原型」以版面 D 為準。
