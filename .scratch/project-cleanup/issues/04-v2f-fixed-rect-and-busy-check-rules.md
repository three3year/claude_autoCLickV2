# 影片轉流程產固定矩形與忙碌檢查的規則

Type: grilling
Status: open

## Question

影片轉流程工具改成直接產`固定矩形`、改用`忙碌檢查`（取代出現等候上限的 wait_gone），規則是什麼？
- 固定矩形怎麼算：範本在影格上的框（相對校準基準點、流程尺度）每邊外推多少（拾取檢查的矩形餘裕是 ≥20%；
  要不要更寬）；畫面邊界怎麼裁；同一範本在多個步驟出現時各步各算還是共用。
- 會捲動的清單（換班列名、好友列表）：工具看得出來嗎（同一範本在不同影格位置漂移）？看不出來就在交付報告標「請拉長」，
  標準是什麼。
- 忙碌檢查：哪些步驟自動勾（點了之後影格裡出現忙碌指示的步驟？所有點擊？拖曳？）；忙碌指示範本怎麼挑。
- 找不到時預設改「停止」後，工具的 defaults 與 skill 文件怎麼跟著改；可選彈窗分岔（1 分支＋skip＋break）寫法不變？
- 自我驗證：拾取檢查三項（縮放餘裕、矩形餘裕、唯一）都做；矩形餘裕不過就標待重拍還是自動放寬矩形。
- 刪掉的東西：原點矩形、按鍵、出現等候上限、九宮格文件；plan-format.md 與 plan.py 對齊。

Answer 寫規則清單；這些規則之後進 D 階段的 spec。
