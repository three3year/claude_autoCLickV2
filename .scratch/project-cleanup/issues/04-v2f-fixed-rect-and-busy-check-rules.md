# 影片轉流程產固定矩形與忙碌檢查的規則

Type: grilling
Status: resolved

## Question

影片轉流程工具改成直接產`固定矩形`、改用`忙碌檢查`（取代出現等候上限的 wait_gone），規則是什麼？
- 固定矩形怎麼算：範本在影格上的框（相對校準基準點、流程尺度）每邊外推多少（拾取檢查的矩形餘裕是 ≥20%；
  要不要更寬）；畫面邊界怎麼裁；同一範本在多個步驟出現時各步各算還是共用。
- 會捲動的清單（換班列名、好友列表）：工具看得出來嗎（同一範本在不同影格位置漂移）？看不出來就在交付報告標「請拉長」，
  標準是什麼。
- 忙碌檢查：哪些步驟自動勾（點了之後影格裡出現忙碌指示的步驟？所有點擊？拖曳？）；忙碌指示範本怎麼挑。
- 找不到時預設改「停止」後，工具的 defaults 與 skill 文件怎麼跟著改；可選彈窗分岔（1 分支＋skip＋break）寫法不變？
- 自我驗證：拾取檢查三項（縮放餘裕、矩形餘裕、唯一）都做；矩形餘裕不過就標待重拍還是自動放寬矩形。
- 刪掉的東西：原點矩形、按鍵、出現等候上限、九宮格文件；plan-format.md 與 plan.py 對齊。

Answer 寫規則清單；這些規則之後進 D 階段的 spec。

## Answer

2026-10-11 grilling 定案。依據：工具現況（`tools/video_to_flow/`：只產原點矩形、不支援 busyCheck、
`plan-format.md` 三處與 `plan.py` 牴觸）；四份在用流程 331 個手框固定矩形量測——有拍攝位置可比的 227 個，
每邊最小餘裕中位數約 32%、矩形約範本 1.7 倍寬／2.5 倍高，拉長（某軸 ≥4 倍）的 12 個，好友列表「訪問基建」23～27 倍高；
29 個矩形不含拍攝位置（同一張圖在別處被用）。

**固定矩形**
1. 各步用它自己影格上挑中的框算（不用範本拍攝位置、不取同範本聯集），每邊外推範本寬高的 50%（矩形＝範本 2 倍寬高）。
   拖曳之後那一步的影格就是捲完的位置，所以框自然是「預期位置＋50%」（同 add5 的窄帶思路）。
2. 計畫可在某一步宣告捲動軸（直向／橫向）：內容每次會變的清單（好友列表、迴圈每輪換一列）用。
   工具把該軸拉到影片兩端，另一軸照 50%。同區段有拖曳、又沒宣告的找圖步驟，交付報告列出請使用者確認。
3. 超出畫面裁到影片邊；貼邊那一側餘裕不足不算失敗、不標待重拍。搜尋範圍比框小的部分執行時照裁（現行行為），存檔不裁到搜尋範圍。
4. 忙碌指示、確認圖、`wait_gone` 的目標同一套規則。
5. 全新流程的計畫必須有校準對；沒寫或影格上量不到＝報錯、不組裝（不產跑不動的流程）。

**忙碌檢查**
6. 只有計畫明寫 `busy_check: true` 才勾，工具不自動勾。skill 教 agent 的標準（任一成立就勾）：影片裡那步之後看得到忙碌指示；
   或那步是送伺服器的操作（領取、確認、換班 ⇄、關簽到……）。skill 附四份在用流程勾的 21 步當例子。
7. 自我驗證兩向只報告、不擋：勾了但之後影格沒看到忙碌指示 → 提醒；沒勾但之後影格看到了 → 列出。
8. 計畫勾了忙碌檢查卻沒設忙碌指示＝報錯。忙碌指示範本照舊從「正在提交反饋至神經……」那段取材。

**自我驗證與待重拍**
9. 拾取檢查三項都做。矩形餘裕照規則算必過，留作防呆；「唯一」不過＝標待重拍、列交付報告，不自動縮框，存檔照寫。

**計畫格式、預設、刪除**
10. 計畫的步驟鍵跟 flow.yaml 一致（`find_click`、`on_fail`、秒……，見[flow.yaml 具體 schema（原型）](02-flow-yaml-schema.md)）；
    計畫不寫 `within`（工具算），另帶影片證據欄位（frame、box、present/absent、捲動軸）。plan.py 驗證層照新鍵重寫。
11. 預設照 02 schema：`on_fail` 沒寫＝停止、`timeout` 10、`interval` 0.3；工具遇預設值不寫出（`defaults.py` 的 interval 0.5 改掉）。
12. 可選彈窗分岔寫法不變：1 分支、開頭找圖 `on_fail: skip`、分支內後續失敗 `break`。
13. 刪：原點矩形、按鍵（計畫寫 key 步驟直接報錯）、出現等候上限、九宮格文字、skill 裡「find_click＋wait_gone 等忙碌」的舊教法。
    交付報告刪「口頭補充的按鍵」一節；「無法用點擊解釋的畫面變化」保留並註明「流程不支援按鍵，請改用點擊」。
    `plan-format.md` 與 `plan.py` 對齊（現有三處牴觸：`base:"region"`、九宮格、busyTarget「只能九宮格」）。

**不在本票**：補充流程（影片只錄一段、插進既有流程，如 add5）放地圖「Not yet specified」——先確認影片與既有流程同倍率，
再沿用既有流程的校準對、決定插在哪一步後。add5 驗收照舊是獨立產一份流程、拾取檢查全過。

這些規則進影片轉流程階段的 spec。
