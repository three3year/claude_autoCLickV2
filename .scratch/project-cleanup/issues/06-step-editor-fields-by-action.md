# 步驟編輯器依動作顯示欄位（原型）

Type: prototype
Status: resolved

## Question

步驟編輯器每種步驟各顯示哪些欄位、哪些隨選項出現？用 `/prototype` 做假對話框讓使用者反應。
保留的欄位集合（ADR 0014）：
- 找圖：範本（選擇／預覽）、找圖設定（限定範圍：不限定／固定矩形；挑選規則四種；比色）、等待逾時、重試間隔、
  找到之後三態；動作＝點擊時才顯示：點擊偏移、生效確認四選一（確認圖出現時才顯示確認圖＋設定）、忙碌檢查；
  更新原點；找不到時；立即比對測試。
- 座標點擊：相對原點偏移 X/Y＋截圖拾取（預設原點）、更新原點、忙碌檢查、生效確認（不確認／原點的圖離開／確認圖出現／
  下一步的圖出現）＋逾時、間隔、找不到時。
- 拖曳：起點／終點偏移＋拾取、拖曳時間、放開前停頓、忙碌檢查、生效確認。
- 等待：毫秒。重複開始：次數。重複結束／分岔結束：跳出後動作。分岔開始／或：無對話框。
拿掉：滑鼠鍵、連點、座標基準下拉、按鍵步驟、出現等候上限。

要決定的：
- 逾時／間隔要不要從每步欄位降成「只有在確認或找圖時顯示」的次要區（折疊）。
- 找圖設定子對話框要不要併進主對話框（限定範圍只剩二選一、挑選規則一個下拉）。
- 預設值（逾時 10 秒、間隔 0.3 秒？四份流程全用 0.3）。

產出：每種步驟的欄位表＋版面圖，連結進本票。

## Answer

（2026-10-12 原型定案：使用者選版面 B，加三點修改後點頭）

**版面 B「兩欄」**：找圖與座標點擊、拖曳都是左右兩張卡；全部欄位攤開、不折疊；
找圖自己的找圖設定（限定範圍／挑選規則／比色）**併進主對話框**，確認圖的找圖設定仍是「設定…」子對話框。

| 步驟 | 左卡 | 右卡 |
|------|------|------|
| 找圖（三態） | 「找什麼」：預覽（約 230×100）、範本（下拉＋選擇…）、限定範圍（固定矩形／不限定＋框選，**座標另起一行**，不限定時收起）、挑選規則（四種都留；第 N 個接在同行，最接近指定點的「原點＋X Y 點選」**另起一行**）、比色、立即比對測試 | 「找到之後」：動作（點擊／不點擊等出現／不點擊等消失）、點擊偏移*、生效確認四選一*、確認圖（只在「確認圖出現」：下拉＋選擇…＋設定…）、忙碌檢查*、原點（更新為這一步的位置）、等待逾時＋「每 N 秒看一次」同一行、找不到時 |
| 座標點擊 | 「位置」：原點＋X Y、截圖拾取＋預設原點、原點 | 「送出之後」：生效確認、確認圖（確認圖出現時）、忙碌檢查、等待逾時＋間隔與找不到時（生效確認不是「不確認」時才出現） |
| 拖曳 | 「位置」：起點、終點、截圖拾取＋預設原點、拖曳時間、放開前停頓 | 同座標點擊 |
| 等待／重複開始／重複結束、分岔結束 | 單欄一列：秒／次數／跳出到此時 | — |
| 分岔開始／或 | 沒有對話框 | — |

\* 只在動作＝點擊時顯示。

- **寬度固定**：兩欄固定寬，切選項、換步驟種類都不跳（原型：左 432 含欄距、右 440，找圖／點擊／拖曳一律 904px；
  實作時照同樣方法量所有選項組合的最寬來定）。確認圖的下拉要比原型寬（長範本名會被截）。
- **確定永遠在畫面上**：底列先 pack；B 版最大展開 475px（工作區 1020），遠低於上限。
- 說明照 05 的說明文字規則：每欄標題旁 ⓘ、⚠ 一行常駐（例「⚠ 下一步要是找圖步驟」）、驗證錯誤顯示在底列一行（不彈窗）。
- **重試間隔**：照 B 攤開、跟逾時同一行（雖然四份流程 409 步全是 0.3）。
- **挑選規則**四種都留（由左到右、最接近指定點雖然 0 次使用）。
- **預設值改成逾時 5 秒**、間隔 0.3 秒維持。

**給 UI 瘦身階段的連帶事項**（逾時預設 10 → 5）：flow.yaml 不寫等於預設的值，四份在用流程裡逾時 10 秒的步驟
（早_簡中 55、早_繁中 30、晚兩份各 21）現在都**沒寫** `timeout`；只改 `flowdefaults.WAIT` 會把它們靜靜變成 5 秒。
改預設前要先把現有流程的這些步驟寫成明確的 `timeout: 10`（一次性腳本，照格式階段轉換工具的做法）。
同步要改：`docs/flow-format.md` 欄位表（對照測試會擋）、`video-measure` 的 plan-format「預設照 app」那行、
相依預設的測試（`test_pointer_confirm_ui` 的「逾時10s」等）。

原型：`prototype/step-editor` 分支的 `app/prototype_step_editor.py`（版面 B＝定案；A 單欄折疊、C 句子式是落選對照）。
