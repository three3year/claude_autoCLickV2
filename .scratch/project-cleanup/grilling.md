## 決策（共識）

### 1. 腳本格式（agent 友善）
- 流程主要由 agent 用影片轉流程產出；app 保有從零建立與手改步驟的能力。
- 一份流程＝資料夾：`flow.yaml`＋`templates/*.png`＋`.cache/`（登錄產物＋未存檔暫存截圖，可重建，隨資料夾搬）。
- 欄位自述性英文名、預設不寫；找不到時沒寫＝停止。範本拍攝位置、校準對、備用對、忙碌指示、搜尋範圍都在 yaml。
- flow.yaml 可選填 `engine:` 段覆蓋引擎參數。
- 一次性轉換工具：輸入打包版 10/10 四份；舊格式讀取碼刪除。
- 一份 flow.yaml 格式規範（欄位、預設、常見模式：定位找圖→相對座標、可選彈窗分岔、忙碌檢查）兩邊共用；
  新增「手寫／修改流程」skill；影片轉流程 skill 只寫影片特有的事。

### 2. 指令類型與條件
- 拿掉（格式＋UI＋執行器）：按鍵步驟、絕對座標、滑鼠鍵、連點數、原點矩形、出現等候上限；
  補做間隔／忙碌出現等候改常數 1000ms；啟動延遲固定 3 秒；避開游標一律開。
- 保留：找圖三態、生效確認四選一、找不到時三選一、挑選規則四種（分數最高／上到下 N／左到右 N／最接近）、
  固定矩形、比色、忙碌檢查、更新原點、點擊偏移、重複與分岔、兩種區段結束的跳出後動作。
- 影片轉流程：直接產固定矩形（範本位置外留 ≥20% 餘裕；會捲動的清單在交付報告標記請使用者拉長）、
  改用忙碌檢查、刪原點矩形／按鍵／出現等候上限、修過期文件；自我驗證套拾取檢查三項（含矩形餘裕）。

### 3. 範本與 profile
- profile 整個退場（含 profile_store、profiles/ 目錄、UI 下拉與建立鈕）；app 開檔選任何位置的流程資料夾；
  本機狀態只記上次開的流程。
- 範本圖＝`templates/<名稱>.png`，檔名即範本名；工作區、步驟草稿退場。
- 基準集搬到根目錄 `benchmark/`，從四份流程的範本＋示範影片影格重製（單張範本）；引擎刪 multi_capture 路徑。
- 搜尋範圍照舊存流程裡；換電腦校準失敗提示重框。

### 4. 精簡
- torch 不動。
- 刪：舞台接縫（stage.py、執行器永不走的分支、測試、詞彙）、profile_store、舊格式讀寫、影片轉流程過期部分、
  README 與 app/CLAUDE.md 重寫。
- 測試：執行器／校準／找圖目標的測試改適保留；UI 與存檔測試重寫。

### 5. UI
- 主視窗只剩：開檔／新流程／存檔、框搜尋範圍、執行模式＋次數、執行／停止、測試選取、步驟清單
  （拖曳排序、編輯、刪除、Ctrl+C/V、摺疊）、範本面板、執行紀錄、「流程設定…」鈕。
- 拿掉：profile 下拉與建立、開啟資料夾、▲▼、⧉、範本的複製／上傳／比對測試／重新整理、校準鈕、
  避開游標勾選、啟動延遲、補做／忙碌 spinbox。
- 流程設定對話框：校準對、備用校準對、忙碌指示，各自可設、可清、可測。
- 範本面板：清單、截圖新增、重截（同名換圖）、重新命名（連動步驟）、刪除；未引用標記。
- 步驟編輯器依動作隱藏無關欄位；比對測試只留這裡。
- 存檔語意：改動在記憶體，按存檔才寫；關閉提示未存檔；開啟讀上次流程；新流程第一次存檔才選資料夾；
  暫存截圖在 .cache，重開／讀檔清掉；存檔後 templates/ ＝ 引用集合（被移除步驟的圖一併移除）。
