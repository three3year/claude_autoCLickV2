# 01 — 執行端：畫面倍率出界開頭不執行

Spec：[../spec.md](../spec.md)。ADR 0013 決策 1（2026-10-11 修正）。

**What to build:** 開頭`校準`量到的`畫面倍率`落在`支援倍率範圍`（×0.85–1.15，閉區間）外時，流程不執行，跟校準對找不到一樣。執行紀錄寫明這次量到的倍率（三位小數）、支援範圍，以及「請把遊戲視窗調大」或「調小」；檔案日誌記一筆範圍外的校準事件。測試選取走同一條路。用主校準對或備用校準對量到的都一樣擋。

先做的整理：支援倍率範圍兩端改成只定義在校準模組，拾取檢查改讀那一份（行為不變）。成功的校準結論多提供「在不在範圍內」與範圍外時的說明文字（調大／調小），給本票與 02 共用。這不是新的失敗種類：校準結論的成功／失敗意義不變，因為編輯器在範圍外仍要照常拾取。

**Blocked by:** None — can start immediately
