# 03 — 找圖相連檢查：純函式＋兩個擋下點

**What to build:** 「找圖相連」規則落地為**模組層級、不依賴 GUI 的純函式**（本功能唯一新測試接縫）：給定步驟清單與索引，判定用了「點到下一步的圖出現」的步驟其緊接下一步是否為找圖（三態皆可）；最後一步、下一步是區段標記或其他類型＝不相連。兩個擋下點接上它：(1) 步驟編輯對話框按確定時不相連 → 警告彈窗並擋下存檔（新增與編輯兩種情境的「下一步」索引語意都要正確——新增時步驟尚未入清單）；(2) 按執行時（含測試選取）不相連 → 警告彈窗並擋下執行，片段恰好結束在該步驟即視為不相連。

**Blocked by:** 02 — 「點到下一步的圖出現」執行路徑

**Status:** resolved

- [x] 純函式測試：下一步為找圖三態各種情形＝合法；最後一步／區段標記／其他類型＝不相連
- [x] 對話框按確定：不相連 → 警告且對話框不關閉、步驟不寫入；新增與編輯兩種索引語意皆正確
- [x] 按執行：不相連 → 警告並不執行（與既有執行前檢查同風格）
- [x] 測試選取片段結束在該步驟 → 同樣警告擋下
- [x] 未用此選項的步驟完全不受檢查影響（既有流程照常執行）
