# 02 — 「點到下一步的圖出現」執行路徑（核心 tracer bullet）

**What to build:** 流程作者在找圖點擊的「點擊後確認」下拉選到第四態**「點到下一步的圖出現」**（code 值 `next`），存出的步驟不記名（`confirmTemplate` 空字串）。執行時：找到本步的圖 → 點一次 → 補點迴圈以「執行清單中下一步的範本圖出現」為生效條件（逾時／interval 為重新起算的一份預算，與 gone/appear 相同）；逾時走該步「找不到時」，訊息措辭為「點擊『A』後 X 秒內未見下一步的圖『B』」。含**執行期防禦線**：執行當下若下一步不存在或不是找圖，記錄警告並退化成「不確認」（點一次就走），不崩潰。步驟摘要文字同步顯示此確認模式。選「不點擊」三態時確認選項照舊隱藏且存為 none。
