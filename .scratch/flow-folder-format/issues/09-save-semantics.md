# 09 — 存檔語意

**What to build:** 任何改動（步驟、範本新增／重截／改名／刪除、校準對、備用校準對、忙碌指示、搜尋範圍、執行輪數）都把流程標成未存檔。有未存檔改動時關閉 app、開檔、開新流程，問「存檔／不存／取消」。新流程到第一次存檔才選位置與名字：對話框從 `%USERPROFILE%\AutoClick\` 開（不存在就建），使用者輸入流程名，app 在選的位置建 `<流程名>\`；已有同名資料夾就拒絕並請換名，什麼都不寫。新流程存檔前的截圖與登錄產物放本機狀態資料夾裡固定的「未存檔」快取，第一次存檔時搬進新資料夾；開新流程、讀取別的流程或重開 app 時清空。見 spec「存檔語意」「範本與快取」。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 每一種改動都標成未存檔；存檔後清除標記
- [ ] 關閉、開檔、新流程三個入口的提示，三種回答（存檔／不存／取消）各自行為正確；取消時什麼都不變
- [ ] 新流程第一次存檔：建 `<流程名>\`、寫入 `flow.yaml` 與 `templates/`、未存檔快取的登錄產物搬進 `.cache/`
- [ ] 同名資料夾已存在：拒絕、說明、什麼都不寫
- [ ] 未存檔快取在開新流程、讀取流程、重開 app 時清空
- [ ] App 存讀檔測試涵蓋以上；全部測試綠
