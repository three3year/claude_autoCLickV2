# 11 — 背景預載

**What to build:** 讀取流程就在背景做`範本預載`（引擎還沒就緒就等就緒後開始，包括 app 啟動時自動開的上次流程）。還沒載完就按執行：接著等同一份，開始延遲仍是從按下起算的 3 秒下限。新增或重截範本只丟那幾張的登錄產物，其他留在記憶體。執行紀錄只印「開始準備範本」「範本就緒」兩行。預載中換流程＝丟掉舊的、開始新的；背景預載發現壞圖當下在執行紀錄印警告，按執行時照舊不開跑並報錯。規則見 [診斷「預載完還再等 3 秒」](../../project-cleanup/issues/03-diagnose-post-preload-wait.md)；見 spec「背景預載」。
