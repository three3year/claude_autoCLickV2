# 02 — 補做間隔、忙碌出現等候、啟動延遲、避開游標改成固定行為；刪舞台接縫

**What to build:** `補做間隔`與`忙碌出現等候`改成程式常數 1 秒，`開始延遲`固定 3 秒，`避開游標`一律開；主視窗的補做／忙碌 spinbox、啟動延遲、避開游標勾選拿掉，存檔不再讀寫這幾個設定。舞台接縫（執行器永遠不走的分支）連同測試刪掉。四份流程行為不變（它們用的值就是這些）。見 spec「子步驟順序」第 1 步。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 開工前先提交工作目錄裡未提交的避開游標改動（移開游標補真實事件），或確認使用者已處理
- [ ] 補做間隔、忙碌出現等候固定 1 秒；開始延遲固定 3 秒（仍是下限語意）；避開游標一律開
- [ ] 主視窗沒有這四個控制項；流程資料不再帶 `retryIntervalMs`、`busyAppearMs`、`avoidHover`、啟動延遲
- [ ] 舞台接縫模組與執行器裡的相關分支、測試、詞彙引用刪掉
- [ ] 只測「可設定」的測試刪掉或改成測固定值；其餘測試全綠
