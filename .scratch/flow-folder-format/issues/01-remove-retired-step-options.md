# 01 — 刪退場的步驟選項

**What to build:** 執行器、步驟編輯器、步驟清單摘要不再有按鍵步驟、絕對座標模式、滑鼠鍵、連點數、以原點為基準的限定矩形、出現等候上限（ADR 0014 決策 4）。四份在用流程沒用到這些，照常開、照常跑。影片轉流程的計畫寫到這些就報錯，說明已退場、影片轉流程階段改用固定矩形。見 spec「子步驟順序」第 1 步與「影片轉流程工具（過渡）」。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 執行器沒有按鍵、絕對座標、非左鍵、連點、原點矩形、出現等候上限的執行路徑
- [x] 編輯器與新增步驟的選單沒有對應的欄位與選項；清單摘要不再顯示它們
- [x] 只測這些路徑的測試刪掉；其餘測試全綠
- [x] 影片轉流程計畫含原點矩形、按鍵、出現等候上限、非預設滑鼠鍵或連點數時報錯，訊息說明已退場；補對應測試
- [x] 舊存檔照常讀寫（四份流程不受影響）
