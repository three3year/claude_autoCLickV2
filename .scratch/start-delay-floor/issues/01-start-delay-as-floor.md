# 01 — 開始延遲變時間下限(範本預載在倒數中進行)

**What to build:** `開始延遲`從按下「執行」那一刻起算,是到`開頭校準`之前的時間下限。`範本預載`和倒數同時進行:預載提早完成就等到到期,超過了預載一完成就開始,不再額外等。主視窗在按下執行的處理一開始記下時間,交給執行器當起點;沒交時以執行器啟動當下為準。引擎的預載每載完一張範本回報一次,執行器趁這時檢查是否到期;到期時預載還沒完成,記一次「等待準備範本完成」。執行紀錄依序為「N 秒後開始執行 (按 F12 可隨時停止)」→「準備範本中…(N 張)」→(到期仍在預載才有)「等待準備範本完成」→「範本就緒」。延遲選「無」時不寫「0 秒後…」,但一定寫「等待準備範本完成」。預載失敗立刻停止報錯。倒數剩下的等待仍可按 F12 停止;上台、開頭校準、無限模式只倒數一次,都不變。測試選取步驟走同一條路徑。

規格:`.scratch/start-delay-floor/spec.md`;詞彙:`app/CONTEXT.md`「範本預載」「開頭校準」;ADR 0004。

**Blocked by:** None — can start immediately
