# 03 — 實跑兩個客戶端

**What to build:** 使用者用打包版各跑一次繁中、簡中早班，確認收取信用點下去後獲得物資真的出現、信用有領到，接著正常採購。

**Blocked by:** 01 — 繁中早班的收取信用改成等獲得物資出現；02 — 簡中早班的收取信用改成等获得物资出現

**Status:** ready-for-human

- [ ] 繁中實跑一次：日誌裡收取信用那一步有確認圖出現（confirm_appear）的紀錄與點擊次數，關彈窗後接著採購。
- [ ] 簡中實跑一次：同上。遇到第一下被吃時，日誌看得到補做、之後获得物资出現；沒遇到不算失敗。
- [ ] 一起觀察 handoff 待辦第 5 項（简中获得物资逾時）是否不再發生。
- [ ] 發現的問題記在本票 Comments，附 `autoclick.log` 的相關紀錄。實跑前先確認使用者在不在、前景是哪個視窗。
