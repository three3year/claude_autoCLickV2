# 03 — 保底組合:照 arkntools 算、加進輸出

**What to build:** 辨識出五個標籤後,工具在同一次輸出裡列出`保底組合`:1–3 個標籤的子集中,招募池裡符合的幹員最低稀有度 ≥4★ 者,附等級(4/5/6)與候選幹員名單;機器人(支援機械)組合另列並註明需 3:50 以下時限。混淆或未辨識的格子不參與。

規格:`.scratch/recruit-tags/spec.md`「保底組合」節。算法以 arkntools 的 `src/views/Hr.vue` 原始碼為準,實作前再核一次。

**Blocked by:** 02 — 辨識五格(組合透過辨識入口輸出與測試)

**Status:** done (2026-10-10)

- [x] 列舉五個標籤的 1–3 子集;候選 = 招募池中標籤集合包含子集全部標籤的幹員;子集不含「高級資深幹員」時剔除 6★。
- [x] 最低稀有度只看 3★–5★(含高資 → 6、資深 → 5);min ≥ 4 才是保底組合,等級 = min。
- [x] 去冗餘:真子集已達相同或更高等級的組合不列;排序:標籤數少者前、等級高者前。
- [x] 機器人:子集含「支援機械」且候選含 1★ 時另列為機器人組合,不混進 4★ 保底。
- [x] 每個組合附候選幹員名單(名字、稀有度);stdout 摘要與 JSON 都含組合與機器人組合。
- [x] 測試透過辨識入口以迷你快照打:高資 6★、資深 5★、單一 4★ 保底、靠 3★ 拉低而不保底、機器人另列、冗餘不列、兩服字面不同但 tagId 相同結果一致。
