# 02 — 基準測試集 + bench 工具

**What to build:** 腳本開發者可以用一個 bench 工具跑完整基準測試集,得到總正確率與漏抓/誤判分項報告。基準測試集建在明日方舟設定檔內,涵蓋:三組模板集(cn/zh/翻新)互測案例(驗證尺度不變性)、負樣本(主體不存在的截圖,驗證誤判防制)、以及既有的舊方法失敗案例。之後每張票的成效都以這個工具的整體數字衡量,而不是單一案例——這是防止調參過擬合的基礎設施,所以刻意排在命中率改善之前。

**Blocked by:** 01 — 行走骨架

**Status:** done

- [x] 基準案例格式固定:截圖 + 模板名 + 預期結果(存在與否、存在時的預期座標),放在設定檔的 benchmark 資料夾,新增案例=丟檔案,不用改程式
- [x] bench 工具輸入設定檔資料夾,輸出總正確率、漏抓數、誤判數與逐案例明細
- [x] 測試集涵蓋:跨模板集互測、負樣本、小模板(≤30px)、半透明線索卡、可變計數文字案例
- [x] 用行走骨架跑出基線數字並記錄(預期低分,作為後續對照)
- [x] bench 工具本身有測試(給定已知案例集,回報數字正確)
