# 03 — 梯度域多尺度粗篩

**What to build:** 腳本開發者用 cn 的模板就能在翻新版(或 zh 版)的截圖中找到目標——不再需要為每種解析度重抓模板。粗篩改在梯度/邊緣域進行(天然抗色偏與亮度差),依 config 的 scale_range 與 aspect_jitter 掃描多尺度與輕微長寬比擾動,輸出前幾名候選與粗篩分數;查詢結果的分數資訊足以讓開發者判讀「為什麼沒中」。

**Blocked by:** 01 — 行走骨架;02 — 基準測試集 + bench 工具

**Status:** done

- [x] 跨模板集互測案例(cn 模板 × 翻新截圖等)在 bench 上的命中率相對基線明顯上升
- [x] 色偏/亮度變化案例命中(梯度域生效)
- [x] scale_range 與 aspect_jitter 由 config 控制,改動即生效
- [x] 接近全螢幕的搜尋區域單次粗篩留在速度預算內(粗篩自身 <100ms 量級,CPU 即可)
- [x] 查詢結果可取得粗篩分數與候選資訊(供 debug 判讀,格式不對外承諾穩定)
- [x] bench 整體數字不因本票對任何既有涵蓋類別倒退
