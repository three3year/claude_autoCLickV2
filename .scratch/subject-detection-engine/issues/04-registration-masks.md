# 04 — 登錄遮罩:主體/可變區分離

**What to build:** 半透明模板(線索卡)在不同背景的實際畫面上能被命中,「0/7」這類可變計數文字的變化不再造成漏抓。登錄階段為每張模板自動生成有效像素遮罩:multi_capture 策略利用同一元素的多組拍攝(cn/zh/翻新)互相比對像素穩定度找出主體與可變區;single 策略在只有單張模板時退化為梯度穩定度啟發式。粗篩改為帶遮罩匹配。遮罩是通用機制——引擎內不得出現針對特定模板的特例。

**Blocked by:** 03 — 梯度域多尺度粗篩

**Status:** ready-for-agent

- [ ] 線索卡案例:同一張線索卡模板在至少兩種不同背景的截圖上命中
- [ ] 可變區案例:計數文字不同(如 0/7 vs 3/7)仍命中
- [ ] mask_strategy 由 config 控制,multi_capture 與 single 皆可運作;單張模板的遊戲不被卡住
- [ ] 線索 1–7 互為負樣本不混淆(遮罩後梯度匹配的細粒度區分)
- [ ] 登錄產物寫入設定檔的 registered 資料夾,查詢時載入而非重算
- [ ] bench 整體數字上升,既有類別不倒退
