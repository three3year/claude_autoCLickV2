# 01 — 找圖步驟引用共用矩形

**What to build:** 新流程的轉換計畫可以在最外層宣告 `shared_rects`（名字 → `frame`、`box`、可選 `scroll`、`why`），找圖步驟與分岔條件用 `rect: "<名字>"` 引用。組裝時工具把容器每邊外推最大成員圖框寬高的一半（無條件進位），有捲動軸就把那一軸拉到影片兩端，超出影片的部分裁掉，再換成相對座標基準點的流程尺度矩形，逐字相同地寫進每個成員的 `within`。成員在自己那一幀挑中的框只要有一部分超出容器，就是工具錯誤。共用矩形的成員不列進「同段有拖曳、沒宣告捲動軸」的待確認清單。

見 spec「計畫格式」「共用矩形的算法」「待確認清單」。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 兩個成員引用同一個共用矩形 → 兩步的 `within` 逐字相同，等於容器每邊外推最大成員框寬高的一半
- [ ] 只有一個成員也可以
- [ ] 共用矩形宣告了捲動軸 → 那一軸到影片兩端，另一軸照外推
- [ ] 容器貼邊被裁 → 裁過的一側不算矩形餘裕沒過，不報錯
- [ ] 成員挑中的框部分超出容器 → 工具錯誤，訊息指出成員、幀與兩個框，資料夾不產生
- [ ] 計畫報錯：引用不存在的名字、宣告了沒人引用、成員同時寫 `rect` 與 `scroll`、宣告裡寫 `within`／`offset`／不認得的鍵
- [ ] 套上共用矩形後照跑「加上固定矩形後挑到的不是同一個」與唯一檢查；有挑選規則的照舊略過唯一
- [ ] 成員不列進捲動待確認；同段沒宣告的其他找圖照舊列
- [ ] 測試只走新流程組裝的公開入口、用合成影片
