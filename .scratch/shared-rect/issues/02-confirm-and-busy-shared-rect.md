# 02 — 確認圖與忙碌指示引用共用矩形

**What to build:** 生效確認 `appear` 的確認圖、忙碌指示也能用 `rect` 引用共用矩形，跟找圖步驟同一套算法與檢查。它們挑中的框一起算進外推量（最大成員框），也一起做「成員在容器內」檢查。`gone` 與 `next` 本來就沿用別步的目標，不另寫。

見 spec「計畫格式」的引用規則。

**Blocked by:** 01 — 找圖步驟引用共用矩形

**Status:** ready-for-agent

- [ ] `appear` 確認圖寫 `rect` → 確認目標的 `within` 等於該共用矩形
- [ ] 忙碌宣告寫 `rect` → 忙碌指示的 `within` 等於該共用矩形
- [ ] 確認圖或忙碌指示是唯一引用者時，共用矩形不算「沒人引用」
- [ ] 它們的框比找圖成員大時，外推量照最大的那個
- [ ] 它們超出容器同樣是工具錯誤
