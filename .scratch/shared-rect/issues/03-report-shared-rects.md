# 03 — 交付報告列出共用矩形

**What to build:** 新流程的交付報告讓使用者能確認 agent 的分組判斷：共用矩形所在那一份區段報告新增 `## 共用矩形`，每個列出名字、`why` 理由、成員步驟（用步驟內容指稱，不寫編號）、有沒有捲動軸；成員跨段時列在第一個成員所在那一段，其他段寫一行指過去。總覽列出所有共用矩形的名字與所在區段的連結。

見 spec「交付報告」。

**Blocked by:** 01 — 找圖步驟引用共用矩形

**Status:** ready-for-agent

- [ ] 區段報告有 `## 共用矩形`，含名字、理由、成員、捲動軸
- [ ] 成員跨兩段時，第一段完整列出、第二段一行指過去
- [ ] 總覽列出每個共用矩形與所在區段的連結
- [ ] 沒有共用矩形的流程，報告不出現這一節
- [ ] 確認圖與忙碌指示成員（票 02 完成後）也列在成員裡
