# 05 — skill 與計畫格式文件

**What to build:** agent 照文件就能正確使用共用矩形。

- **video-measure**：什麼時候宣告共用矩形（同一個容器裡、每次出現在哪一格不一定的目標，例：商店商品格），什麼時候只用捲動軸（內容會捲動的單排清單）；容器要框整個容器的所有格子，挑容器完整可見的那一幀；`why` 怎麼寫；讀驗證結果時遇到「成員超出容器」就重框容器。
- **計畫格式文件**：`shared_rects`、`rect`、`same_as` 的鍵、可用位置與報錯情況。
- **edit-flow**：補充時新成員用 `same_as`；不靠影片手動加同組成員時，照抄同組既有步驟的 `within`，並照現有規定同步交付報告。

改 skill 時照 writing-for-agents 的寫法。

見 spec「Skill 與文件」。
