# 03 — 校準翻新、失敗處理與未校準警告

**What to build:** 已有校準對的 profile,使用者按校準按鈕即翻新本機倍率:量當前距離 ÷ 基準距離,更新倍率與機器指紋,按鈕顯示跟著更新。任一張找不到=校準失敗:報明原因、舊倍率維持不動。「未校準」狀態(從未校準、或機器指紋與當下螢幕配置不符)下執行流程:警告「尚未校準,座標可能偏移」但可執行,以倍率 1 代入。

**Blocked by:** 02 — 指定校準對與首次校準。

**Status:** ready-for-agent

- [ ] 校準翻新:成功後倍率=當前距離÷基準距離、指紋更新;基準距離不動
- [ ] 校準失敗(缺任一張)報明哪一張沒找到,倍率與指紋保持原值
- [ ] 未校準判定為校準模組純函式:無倍率、或指紋不符 → 未校準;直接以檔案狀態測(含「整包 profile 複製到指紋不同的機器」情境)
- [ ] 未校準執行:警告一次後照跑、落點以倍率 1 換算;已校準執行無警告
- [ ] 沒有校準對的 profile 執行完全無警告、無換算(回歸)
