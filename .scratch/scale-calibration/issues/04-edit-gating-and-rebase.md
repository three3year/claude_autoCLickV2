# 04 — 編輯守門與重定基準

**What to build:** 讓流程檔座標永遠維持「當前基準機器」的尺度。(1) 未校準守門:有校準對但未校準時,拾取座標/偏移前擋下並要求先校準(沒有校準對的 profile 不擋)。(2) 編輯期不混尺度:拾取到的本機像素先以現行倍率反除、歸一到現行基準暫存於步驟;拾取預設原點的推算用同一套換算。(3) 重定基準:在倍率≠1 的機器上存流程檔時自動觸發並告知——profile 內所有流程檔(含自動存檔)座標乘上現行倍率改寫、基準距離改為本機量值、倍率歸 1、指紋更新。

**Blocked by:** 03 — 校準翻新、失敗處理與未校準警告。

**Status:** ready-for-agent

- [ ] 未校準時拾取被擋下並提示先校準;已校準或無校準對時拾取照常
- [ ] 倍率≠1 時拾取值反除歸一暫存;倍率 1 時拾取路徑與現狀等價(回歸)
- [ ] 重定基準為校準模組純函式:以檔案狀態測——含各類步驟(找圖偏移、prev、abs、drag)的流程檔改寫後,每個座標欄位=原值×倍率四捨五入;基準距離、倍率、指紋同步更新
- [ ] 存檔時倍率≠1 → 自動重定+告知訊息;倍率=1 存檔不觸發、不改寫任何其他流程檔
- [ ] 重定涵蓋 profile 內全部流程檔與自動存檔,漏一份=混尺度,測試需驗多流程情境
