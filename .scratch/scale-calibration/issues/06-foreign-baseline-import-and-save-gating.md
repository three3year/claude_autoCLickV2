# 06 — 不同對匯入與存檔守門

**What to build:** 匯入 pack 時,目標 profile 已有校準資料、但校準對與 pack 不同(無共同比例尺)→ 流程照 pack 尺度落地,流程上記「來源基準」標記(pack 校準對範本名與基準距離)並警告使用者此流程尚未歸位。帶標記的流程存檔前守門:必須先完成換算(對 pack 的校準對做一次量測、依比值換算座標後移除標記),或由使用者明確確認以匯入的基準存檔(確認後移除標記)。

**Blocked by:** 04 — 編輯守門與重定基準;05 — flow pack 攜帶校準對與匯入換算(無/同對)。

**Status:** resolved
