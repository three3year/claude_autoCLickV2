# 02 — 指定校準對與首次校準

**What to build:** 使用者在主視窗常駐按鈕區指定校準對:從範本庫選兩個既有範本,指定當下立刻校準一次——清場截圖、經辨識單一路徑(注入的偵測器 `query`,量測前先確保登錄完成)找到兩張圖,以匹配框中心直線距離作為基準距離寫入,本機倍率記 1、附機器指紋。按鈕顯示當前倍率;沒有校準對的 profile 顯示可指定,行為不受任何影響。指定時任一張找不到=指定失敗,報明哪一張沒找到,不寫入任何校準資料。

**Blocked by:** 01 — 校準模組與執行期倍率套用。

**Status:** ready-for-agent

- [ ] 校準模組提供量測純函式:吃 query 形狀的偵測介面與兩個範本名,回傳兩匹配框中心距離(或指明哪張沒找到的失敗結果)——用既有 harness 假 query 直接測
- [ ] 校準的找圖語意與一般找圖一致:有搜尋範圍就在範圍內找,否則全螢幕;截圖走清場 session
- [ ] 指定成功後 profile 內落地:校準對範本名、基準距離、倍率 1、機器指紋
- [ ] 主視窗常駐按鈕區:指定校準對入口+當前倍率(或「未校準」)顯示;新樣式/色票由既有掃描測試涵蓋
- [ ] 指定失敗訊息指明缺哪一張,且不留下部分寫入的校準資料
