# 03 — 應用層引擎生命週期與比對測試

**What to build:** app 啟動時建立一次引擎(驗證模型常駐),載入 arknights 遊戲設定檔並自動登錄;驗證模型載入失敗時降級 coarse-only 並在 UI 明確警告(不靜默)。「立即比對測試」改顯示引擎查詢結果:框出 box、顯示分數,達標/未達標以顏色區分。範本瀏覽器支援多截圖範本目錄(顯示、測試、刪除;GUI 截圖仍存單檔範本)。步驟編輯器裡引用範本的預期座標解析(呼叫端知識)照舊運作。

**Blocked by:** 02 — runner 偵測接縫換引擎

**Status:** done (2026-08-15) — 真機 demo 留待使用者手動驗證

實作備註:
- 範本名全面改用引擎範本名(相對路徑不含副檔名);app 建立的範本以目錄形式落地
  (`<name>/<name>.png`)——資料夾內只有影像檔會被引擎當成一個多截圖範本,
  目錄形式避開歧義,也讓「丟截圖進同目錄→自動變多截圖範本」順理成章。
- 編輯對話框的「立即比對測試」遇到未存檔的新截圖會先存檔登錄再測
  (與確認圖同慣例:取消對話框範本仍會留下)。
- 引擎新增 `Engine.coarse_only` 屬性(公開唯讀,不影響既有測試)。
