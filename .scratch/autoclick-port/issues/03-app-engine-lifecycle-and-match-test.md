# 03 — 應用層引擎生命週期與比對測試

**What to build:** app 啟動時建立一次引擎(驗證模型常駐),載入 arknights 遊戲設定檔並自動登錄;驗證模型載入失敗時降級 coarse-only 並在 UI 明確警告(不靜默)。「立即比對測試」改顯示引擎查詢結果:框出 box、顯示分數,達標/未達標以顏色區分。模板瀏覽器支援多截圖模板目錄(顯示、測試、刪除;GUI 截圖仍存單檔模板)。步驟編輯器裡引用模板的預期座標解析(呼叫端知識)照舊運作。
