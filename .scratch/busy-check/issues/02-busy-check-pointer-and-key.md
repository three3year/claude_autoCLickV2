# 02 — 座標點擊、拖曳、按鍵的忙碌檢查

**What to build:** 流程作者能在座標點擊、拖曳、按鍵步驟勾「忙碌檢查」,在主視窗設「忙碌出現等候」。執行時勾了的步驟:送出輸入 → 等忙碌指示消失 → 生效確認(有設的話)。忙碌出現等候內沒看到就放行;看到就等它消失,從送出起最多 60 秒,等不到停止流程。流程沒設忙碌指示卻有步驟勾了,執行前擋下。

規格:`.scratch/busy-check/spec.md`(執行器:忙碌檢查、日誌、流程存檔、編輯器、接縫一~三);ADR 0011;詞彙「忙碌檢查」「忙碌出現等候」見 `app/CONTEXT.md`。

**Blocked by:** 01 — 移除忙碌暫停
