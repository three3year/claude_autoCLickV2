# 02 — 引擎:一次查詢回報所有匹配

**What to build:** `查詢`改為回報主體在搜尋區域中的所有`匹配`(零到多個),每個帶邊界框與分數;沒有匹配時仍提供
最高分與未過哪一關的資訊。粗篩不再每個尺度只取一個峰:每個尺度取所有過匹配門檻的局部峰,跨尺度
NMS 後的候選上限調高到足以涵蓋一排十來個同款;每個候選照舊精修、批次嵌入驗證。

原本「找到沒、找到哪」的結果保留,意義為分數最高的那個匹配,所以 app 端不必同時改、行為不變。
見 spec「引擎(主體偵測)」與 ADR 0007。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 用 demo 影格做的固定素材:基建總覽畫面上四張製造站卡全部回報為匹配(demo3 f300、demo2 f662/f683)
- [ ] 單一實例的既有情境回報恰好一個匹配,位置與改動前相同
- [ ] 無匹配時可取得最高分與未過的關卡
- [ ] 這些案例補進基準測試集;基準測試集全過
- [ ] app 與影片轉流程的既有測試不改程式仍全綠
