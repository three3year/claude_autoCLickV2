# 03 — 找圖目標模組、挑選規則與消失語意

**What to build:** 新增共用的`找圖目標`模組:給定找圖目標、偵測器、搜尋範圍截圖、原點、畫面倍率,回報所有匹配
(螢幕座標)、挑中的那個(或沒挑到與原因),另提供「這個位置是否仍有匹配」。偵測器介面(含
EngineHub 與測試用假偵測器)改成回傳所有匹配。執行器所有找圖點(找圖三態、點擊後確認三種、
分支條件)改走這個模組。

`挑選規則`四種全做:分數最高(預設)、由上到下第 N、由左到右第 N(同列判定:中心 y 差小於半個框高)、
最接近指定點(以原點或搜尋範圍為基準,× 倍率)。匹配不足 N ＝沒挑到,繼續輪詢到逾時。
「目標圖消失」與`等待消失`只看先前挑中的位置;「點到下一步的圖出現」用下一步的找圖目標與點擊後原點;
確認圖用它自己的找圖目標。指定點的像素值納入重定基準與匯入換算。

完成後手改流程存檔加上挑選規則即可實跑看到效果(編輯器 UI 在 07)。見 spec「找圖目標模組」「執行器」。

**Blocked by:** 01、02

**Status:** ready-for-agent

- [ ] 找圖目標模組有自己的測試(假偵測器直接驅動):各規則排序、同列判定、N 不足、指定點兩種基準與倍率、以原點為基準卻沒有原點、位置容差
- [ ] 執行器測試(多匹配假偵測器):四張同款時「由上到下第 3」點到第三張;同款仍在時「目標圖消失」成立;等待消失看挑中位置
- [ ] 「下一步的圖出現」套用下一步的挑選規則;確認圖套用自己的挑選規則;分支條件套用條件步驟的
- [ ] 沒設挑選規則的舊流程行為不變(既有執行器測試全綠)
- [ ] 指定點像素值在重定基準與匯入換算時被換算
- [ ] 編輯器比對測試與影片轉流程自我驗證暫時照舊可用
