# 05 — 限定範圍

**What to build:** 找圖目標可設`限定範圍`三選一:不限定、以原點為基準的矩形(× 畫面倍率)、搜尋範圍九宮格勾選的格子
(多格取最小包圍矩形)。找圖目標模組先算出限定矩形、裁到搜尋範圍內、裁圖再查詢,匹配座標換回螢幕。
以原點為基準卻沒有原點 ＝ 該步驟無法執行(與相對座標同處理)。原點矩形的像素值納入重定基準與匯入換算
(九宮格是比例,不換算)。新欄位名不得與編輯器會丟棄的舊 `region` 衝突。

見 spec「找圖目標模組」。

## Comments

- 存檔欄位: 找圖目標的 `limit`: `{"kind": "origin", "x", "y", "w", "h"}`(相對原點的
  矩形, 基準尺度) 或 `{"kind": "grid", "cells": [1..9]}`(由左上起逐列編號)。
- 限定矩形完全在搜尋範圍外＝沒有匹配、不查詢。「最接近指定點」以搜尋範圍為基準時,
  基準仍是整個搜尋範圍的左上 (不受限定範圍裁切影響)。
- 測試選取的片段檢查 (`_fragment_origin_error`) 也擋下「原點來源之前、找圖目標以
  原點為基準」的找圖步驟 (同相對座標)。
