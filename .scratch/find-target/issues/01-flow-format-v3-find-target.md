# 01 — 存檔格式 v3:找圖目標收成巢狀

**What to build:** 找圖步驟的範本與確認圖的範本各自收進一個`找圖目標`物件(目前只有範本名;限定範圍、挑選規則、比色
欄位留給後續票),存檔蓋章 `flowFormat` 3。舊資料一律單向遷移:v2 流程存檔、`步驟草稿`、舊 JSON、
舊 `.autoclickpack` 讀入時把原本的範本名與確認圖範本名搬進對應的找圖目標。所有讀範本名的地方
(執行器、編輯器、範本引用收集、影片轉流程的計畫與組裝)改讀新位置。

這是預備重構:**使用者看得到的行為完全不變**,舊流程開起來照跑。見 spec「存檔格式(flowFormat 3)」。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] v2 存檔、步驟草稿、舊 JSON、舊 `.autoclickpack` 讀入後,找圖步驟與「確認圖出現」的範本都在對應找圖目標裡;寫出蓋 3
- [ ] 存檔只收被任何找圖目標(含確認圖)引用到的範本,與遷移前收的集合相同
- [ ] 重定基準、匯入換算對遷移後的步驟結果與遷移前相同
- [ ] 影片轉流程組裝產出的存檔是 v3
- [ ] 既有測試全綠(必要的測試資料改成新結構或改由遷移產生)
