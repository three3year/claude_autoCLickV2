# 08 — 影片轉流程支援找圖目標

**What to build:** 計畫的找圖步驟與確認圖可寫比色、挑選規則、限定範圍。矩形與指定點寫影片像素的畫面位置並註明基準
(原點或搜尋範圍),組裝依該步原點換成相對值並換回基準尺度。自我驗證改走找圖目標模組:取材幀與
present 幀上挑中的匹配要在預期位置、absent 幀上挑不到、步驟幀照步驟的找圖目標挑。設定不完整
(以原點為基準卻沒有原點、N < 1、九宮格格號無效)時組裝拒絕。工具不自動判斷也不給提示。

skill 與計畫格式文件加上欄位說明與判斷規則:何時開比色(形狀相同只差顏色、absent 幀會被匹配)、
何時用哪種挑選規則(同款多張)、何時設限定範圍(定位物附近、固定角落)。

**Blocked by:** 04、05

**Status:** ready-for-agent

- [ ] 合成影片測試:同款多張時「由上到下第 N」驗證通過且點對;規則設錯被標待重拍
- [ ] 合成影片測試:限定範圍與指定點從影片像素換算正確(含畫面倍率≠1)
- [ ] 合成影片測試:只差顏色的 absent 幀,開比色後不再被匹配
- [ ] 組裝拒絕不完整設定且 profile 不多任何檔案
- [ ] skill 與計畫格式文件更新
