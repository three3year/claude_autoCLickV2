# 07 — 編輯器:找圖目標設定與比對測試

**What to build:** 找圖步驟與確認圖共用一個找圖目標子表單:範本、限定範圍(框選原點矩形並預先標示預設原點/3×3 勾選)、
挑選規則(種類、N、點選指定點與基準)、比色勾選。未校準時擋下像素類拾取並要求先校準。
「立即比對測試」照找圖目標完整執行(經找圖目標模組),畫出限定矩形、所有匹配與各自分數(含比色)、
會被挑中的那個。步驟清單對有設比色、挑選規則或限定範圍的找圖步驟加簡短標記。

UI 不寫自動測試,由使用者實跑驗收;非 UI 的換算邏輯若有新增仍要測。

**Blocked by:** 04、05

**Status:** ready-for-agent

- [ ] 找圖步驟與確認圖都能設定並存回四個屬性,重開編輯不遺失;按確定不會丟掉新欄位
- [ ] 原點矩形與指定點以基準尺度存檔(除以畫面倍率),與相對座標拾取一致
- [ ] 未校準時拾取原點矩形與指定點被擋下
- [ ] 比對測試畫面與執行時挑中的一致(同一模組)
- [ ] 步驟清單看得出有特別設定的找圖步驟
- [ ] 使用者在打包版或開發版實際操作驗收(列為人工步驟)
