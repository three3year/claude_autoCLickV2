# 03 — 截圖新增／重截／固定矩形：覆蓋層立刻出現

**What to build:** 按「截圖新增」「重截」或框固定矩形時，覆蓋層馬上出現讓你框，校準在你框的同時於背景完成。框完視窗還原，校準還沒好就以辨識中等它。範本在拿到倍率與基準點後才存進本流程，縮放餘裕檢查接著在同一件背景辨識裡做，做完寫紀錄、標 ⚠。

失敗與取消的處理：

- 校準在覆蓋層顯示中失敗（例：校準對被彈窗擋住）：覆蓋層立刻關，視窗還原後警告，什麼都不存。
- 按 Esc 取消：背景結果作廢。
- 辨識中關掉整個應用：照原本的未存檔詢問關閉，結果丟棄。

本票的範圍：

- 入口：範本面板的截圖新增與重截、步驟編輯器的截圖新增、選範本對話框的現場截圖、找圖設定的固定矩形。
- 拾取骨架（`measured_pick`）改成：清場中截一張整個虛擬桌面的圖、啟動背景校準（裁搜尋範圍那塊量）、把這張圖交給覆蓋層顯示 → 還原 → 背景還沒做完就進辨識中。
- 覆蓋層拾取入口改收兩個參數：
  - 預先截好的圖：不再自己另截。
  - 「待定結果」：還沒好時提示列顯示「辨識中…」；失敗時覆蓋層結束並回傳中止。
- 新範本的登錄產物載入（`hub.ensure_template`）移到背景；`ensure_registered` 留在介面執行緒、在派出背景工作前做。
