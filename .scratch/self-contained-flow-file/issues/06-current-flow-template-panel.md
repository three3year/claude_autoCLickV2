# 06 — 範本面板改成「本流程的範本」

**What to build:** 主視窗的範本瀏覽器不再是 profile 範本庫的檔案總管,改成**本流程的範本清單**——使用者一眼看得出這份流程到底帶了哪些圖。

資料夾層級整個移除:一份流程幾十張圖,不需要命名空間。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 面板只列出本流程的範本,切換流程時跟著換
- [ ] 預覽:選取範本時看得到圖與尺寸
- [ ] 重新命名:同步改寫所有引用它的步驟(含`確認圖`)
- [ ] 刪除:從本流程移除該範本,引用它的步驟以既有方式標示為有問題
- [ ] 單一範本可直接跑`比對測試`,走既有的就緒 gating 與`清場`
- [ ] 資料夾建立／展開收合／跨資料夾搬移等範本庫時代的操作全部移除
- [ ] 面板的色票與樣式沿用既有 UI 慣例,且通過既有的色票／樣式掃描測試
- [ ] 只有互動才會執行到的路徑(選取、重新命名、刪除)以事件模擬真的走一遍,不只拍靜態畫面
