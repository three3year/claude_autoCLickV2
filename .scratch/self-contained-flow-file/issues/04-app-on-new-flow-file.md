# 04 — app 改走新存檔(第一個使用者看得到的切片)

**What to build:** 讓整條路走通:開新流程 → 拍圖 → 存檔 → 關掉 app → 重開 → 載入 → 執行。存檔是一個自包自足的檔,本機不再有範本庫。

profile 只剩引擎參數設定、校準資料與流程存檔目錄;範本庫目錄與登錄產物目錄從 profile 消失。判定一個資料夾是不是 profile 改看引擎參數設定檔是否存在。

工作區生命週期綁上流程切換:載入流程＝解到工作區,**切換流程＝工作區整個清空**(解出來的圖與`登錄產物`一起刪)。自動存檔只寫步驟草稿,不重壓整包 zip——拖曳排序步驟時不能因為重寫幾十張圖而卡頓。

**執行期行為零變化**是這張票的硬性驗收條件。

順手把 repo 的開發用資料轉成新格式(用票 03 的轉換規則),讓後續每一張票都有真實流程可以驗收。**打包版的正式資料這張票不碰**,等票 09。
