# 08 — 匯出移除、匯入保留、開啟外來檔

**What to build:** 存檔本身就是可搬移的檔,所以**匯出動作消失**——要給別人就直接複製檔案。

**匯入保留**,職責縮小成兩件事:舊格式(舊 autoClick flow JSON、舊流程包)的單向轉換,以及外來檔的複製落地。

開啟一份不在本 profile 裡的存檔＝**複製一份副本進 profile 再開**,之後的存檔寫進副本、原始檔不被動到;`匯入換算`也只在這一刻做一次。

**Blocked by:** 04, 05

**Status:** ready-for-agent

- [ ] 匯出動作(選單／按鈕)移除
- [ ] 開啟不在 profile 內的存檔時複製副本進來,原始檔不被修改,之後存檔寫進副本
- [ ] 開啟外來檔時做一次`匯入換算`,三分支結果如實回報給使用者
- [ ] 舊 autoClick flow JSON 與舊流程包仍可匯入,轉成新格式落地
- [ ] 舊格式匯入的既有規則不變:座標空間遷移、每步 `threshold` 安靜丟棄、範本引用去副檔名
- [ ] 舊流程包帶進來的多截圖範本依既定規則取登錄基準張
- [ ] 匯入結果(補進的範本、改名的範本、校準三分支)寫進執行紀錄
- [ ] 匯入相關的既有測試全數通過
