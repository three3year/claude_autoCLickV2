# 07 — 選範本對話框(跨存檔瀏覽、確定才複製)

**What to build:** 找圖步驟選範本時,使用者能看到本流程已有的範本、展開 profile 內**其他流程存檔**看它們的範本縮圖,也能直接從磁碟挑任意 PNG。

**按下確定的那一刻才複製。** 取消就等於什麼都沒發生——包括在對話框裡現場拍的新截圖,取消時一併丟棄(現行`確認圖`「截圖即時存檔、取消對話框圖仍留下」的行為要改掉)。

撞到同名時自動加序號並改寫引用,所以複製進來永遠不會蓋掉本流程已有的圖。

加入範本後提示「建議跑一次`比對測試`」——**不自動比對**(自動比對需要`清場`截圖與`引擎就緒`,成本與時機都不合適)。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 對話框左側樹狀列出「本流程」與本 profile 內其他流程存檔,可展開看各自的範本
- [ ] 列出其他存檔的範本時只讀索引與縮圖,不整包解壓
- [ ] 右側預覽顯示名稱、尺寸與來源
- [ ] 提供從磁碟挑任意 PNG 的入口
- [ ] 按確定才把圖複製進本流程;按取消時檔案系統完全沒有變化
- [ ] 在對話框裡現場截圖後按取消＝那張圖被丟棄(`確認圖`的截圖路徑一併改成同一語意)
- [ ] 撞名自動加序號並改寫引用,改名結果寫進執行紀錄(不彈對話框)
- [ ] 加入範本(上傳或截圖)後提示建議跑`比對測試`
- [ ] 對話框在`引擎就緒`之前可正常開啟與挑圖,只有比對類動作被既有 gating 擋下
- [ ] 「確定才複製 / 取消不留痕」以事件模擬真的走一遍並斷言檔案系統狀態
- [ ] `清場`與 modal 堆疊的既有紀律不變(不自行 withdraw/deiconify、子視窗走既有 modal 入口)
