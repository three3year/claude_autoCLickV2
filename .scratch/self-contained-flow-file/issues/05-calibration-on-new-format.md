# 05 — 校準在新格式下

**What to build:** 把 ADR 0005 的整條校準線在新存檔格式上重新站穩。

`校準對`的兩張圖改由 **profile 自己存一份**(指定校準對時把選中的圖複製進 profile),與流程存檔解耦——刪掉任何一份流程都不會弄壞校準。

存檔繼續攜帶`校準對`名稱、`基準距離`與那兩張校準圖,讓`匯入換算`三分支(採用 / 依基準距離比值換算 / 標記`來源基準`並警告)語意完全不變。

`重定基準`照舊改寫 profile 內**每一份**流程存檔的步驟座標(含草稿),zip 內的圖不動。漏改任何一份就是混尺度。

**Blocked by:** 04

**Status:** resolved

## Comments

- `校準對`的兩張圖由 profile 自存（`<profile>/calibration/<名稱>.png`，`flowfile.store_calibration_images`）；量測從自存圖取範本，交給引擎時加 `_cal/` 前綴（流程範本名一律被 `clean_name` 擋掉斜線 → 永不撞名）。刪掉/搬走任何一份流程後校準照樣量得出來，有測試守著。
- 存檔攜帶校準對名稱、基準距離與那兩張圖（zip 內 `calibration.json` + `calibration/*.png`），與 `templates/` 分開放（校準圖不被步驟引用，不該混進本流程的範本清單）。
- `匯入換算`三分支改在 `flowfile._apply_import_calibration`，三條路都有測試（無校準資料＝採用／同一對＝依比值換算／不同對＝`來源基準`標記）。
- `重定基準`改寫 profile 內每一份 `.autoclickpack`（只換 `flow.json`，zip 內的圖一個 byte 不動）＋步驟草稿；帶 `來源基準` 標記的跳過。
- 沒有校準對的 profile 一切照舊（既有回歸線全綠）。
