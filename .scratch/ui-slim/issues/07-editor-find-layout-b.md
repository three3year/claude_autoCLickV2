# 07 — 步驟編輯器：找圖步驟版面 B

**What to build:** 開找圖步驟時是兩欄：左「找什麼」（預覽、範本、限定範圍、挑選規則、比色、立即比對測試），右「找到之後」（動作、點擊偏移、生效確認、確認圖、忙碌檢查、原點、等待逾時＋每 N 秒看一次、找不到時）。限定範圍、挑選規則、比色直接在主對話框設，不用再開「找圖設定…」。切任何選項寬度都不變，確定鈕永遠在工作區內；按確定的驗證錯誤顯示在底列一行，不彈窗。

見 spec「步驟編輯器（06 版面 B）」與 06 Answer 的欄位表；原型 `prototype/step-editor` 分支（`python app/prototype_step_editor.py B`，左邊清單是早_簡中的真步驟樣本）。

**Blocked by:** 01 — ⓘ 說明提示元件

**Status:** ready-for-agent

- [ ] 左卡：預覽約 230×100；範本下拉＋選擇…；限定範圍（固定矩形／不限定＋框選，座標另起一行，不限定時收起、框選停用）；挑選規則四種（第 N 個同行，最接近指定點的「原點＋X Y 點選」另起一行）；比色；立即比對測試
- [ ] 右卡：點擊偏移、生效確認、忙碌檢查只在動作＝點擊時出現；確認圖（下拉＋選擇…＋設定…）只在確認圖出現時出現；確認圖下拉寬到看得到最長範本名
