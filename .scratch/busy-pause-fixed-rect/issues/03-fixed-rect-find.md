# 03 — 固定矩形:找圖時會用

**What to build:** 找圖目標的限定範圍新增第四種「固定矩形」,存成搜尋範圍的比例(左、上、寬、高,各 0–1)。找圖時只在「比例 × 當下搜尋範圍」那一塊裡找。步驟清單上標〔限定〕,摘要寫出是固定矩形。做完後,建構腳本可以直接寫入固定矩形,執行器也照著找。編輯器 UI 在 04。

規格:`.scratch/busy-pause-fixed-rect/spec.md`(固定矩形一節、接縫一);詞彙「固定矩形」「限定範圍」見 `app/CONTEXT.md`。

**Blocked by:** None — can start immediately
