# 08 — 早班兩版加固定矩形

**What to build:** 早_簡中、早_繁中所有位置固定的圖都加上固定矩形,讓換班、採購這些找圖從 1–2 秒變成幾乎瞬間。目標是換班時貿易站找到後很快點到箭頭,採購每一輪購買明顯比 10/07 的約 10 秒短。

規格:`.scratch/busy-pause-fixed-rect/spec.md`(流程改動 → 固定矩形、接縫三、Further Notes 的 10/07 量測)。

**Blocked by:** 07 — 快速置入看線索板狀態

**Status:** ready-for-agent

- [ ] 加固定矩形的範圍照規格列的清單:開頭彈窗、基建、待辦、線索板、換班清單、好友、採購。採購的 23 個商品分支共用一個商品區矩形。
- [ ] 不加:位置會隨基建地圖縮放、平移改變的圖(例如會客室、製造站卡片相關步驟)。位置固定的判斷依據是:在所有可用的參考影格上都出現在同一位置。
- [ ] 已有「以原點為基準」限定範圍的步驟維持原樣;用九宮格的可以換成更緊的固定矩形。
- [ ] 框的大小:位置固定的圖,把影格上量到的框外擴一點;換班清單沿捲動方向拉長,涵蓋整段。
- [ ] 框由建構腳本從影格量出,使用者不審框。
- [ ] 真引擎驗證:每個加了固定矩形的步驟,在該出現的影格上仍找得到,位置在容許值內;記錄改前改後的查詢時間。
- [ ] 改前備份;透過流程存檔模組讀寫;`_autosave.json` 一致。
- [ ] 兩份 `.md` 加一節:加了哪些框、驗證結果、查詢時間比較、已知風險(別天位置變了會逾時,放寬那個框就好)。
