# 01 — 交付報告的三個程式錯

**What to build:** 補充插入後，交付報告不再自相矛盾、清單照流程順序、描述沒有多餘標點。見 [規格](../spec.md)「報告程式錯」。

1. 補充新增一份段落報告時，總覽「各段報告（依流程順序）」的連結插在它在流程中的位置，不接在清單最後。
2. 往待重拍或待確認一節加入第一個條目時，拿掉原本寫「無」的那行。段落報告與總覽都一樣。
3. 段落描述把區段開頭的字樣（「分岔：」「重複 N 次：」）與第一個步驟接起來時，不多加分隔號，不再出現「分岔：；」。

**Blocked by:** None — can start immediately.

**Status:** done
