# 03 — 遞補方向：只往一邊遞補的一排項目，框朝那一端拉長

**What to build:** Claude 在計畫裡對只往一邊遞補的一排項目（例：待辦列）宣告`遞補方向`，工具產的固定矩形從影片那一端拉到目標在影片裡的位置，跟同一列其他項目的框同一套邏輯。見 [規格](../spec.md)「遞補方向」相關決策與實作決策。

- 計畫的找圖步驟（含分岔條件）收 `shift`，值只能是 `left`、`right`、`up`、`down`。
- 挑框、外推一半照舊，再朝宣告方向延伸到影片邊緣，超出影片的部分照舊裁掉；另一軸不動。
- 遞補方向不觸發「有捲動就要寫對齊」的規則。
- `shift` 跟 `drift`、`scroll`、`rect` 任一同寫都報錯；寫在找圖以外、值不認得也報錯。
- 「同段有拖曳、沒宣告捲動軸」的待確認也排除宣告了遞補方向的找圖。
- 段落報告的固定矩形說明列出用了遞補方向的步驟與方向（沿用 02 的區塊）。
- 文件：計畫格式文件、video-measure skill「挑幀取材」、格式規範「固定矩形的餘裕」。
