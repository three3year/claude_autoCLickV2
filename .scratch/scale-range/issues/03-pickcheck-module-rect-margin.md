# 03 — 拾取檢查模組與矩形餘裕

**What to build:** 新的「拾取檢查」純模組(自動化子套件內,偵測器注入,回警告清單),先長出第一項:編輯器找圖設定子對話框框完固定矩形,立刻對照該找圖目標的範本告訴使用者每邊餘裕夠不夠 20%、至少該框多大;只警告不擋存檔。

規格:`.scratch/scale-range/spec.md`「拾取檢查」一節、user stories 9–11。接縫:新純模組的單元測試(前例 `test_findtarget.py` 假偵測器)、編輯器對話框測試(前例 `test_fixed_rect_ui.py`)。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 純模組介面定下來:輸入偵測器、搜尋範圍截圖、找圖目標(範本名、限定範圍、挑選規則、比色)、當下座標基準點與倍率;輸出警告清單,每則有種類(縮放餘裕/矩形餘裕/唯一)、一句人看的話、關鍵分數。三個常數(粗篩 0.7、驗證 0.85、矩形 20%)住在模組裡。縮放餘裕與唯一兩項此票可先留空殼。
- [x] 矩形餘裕:限定範圍為固定矩形時,以該目標範本的流程尺度寬高算,左右各至少多寬的 20%、上下各至少多高的 20%;不足就警告並給「至少 W×H」的建議;找圖目標還沒選範本就跳過;不需要偵測器。
- [x] 找圖設定子對話框框完固定矩形後,在對話框內顯示警告(有則顯示、通過則清除);按確定照存。
- [x] 單元測試:50×50 範本對 58×58 矩形警告並建議至少 70×70;72×72 不警告;沒範本不警告。對話框測試:框出不足的矩形後對話框出現警告字樣,存檔內容不受影響。
