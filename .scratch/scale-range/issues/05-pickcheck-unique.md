# 05 — 拾取檢查:唯一

**What to build:** 找圖設定子對話框按確定時,以及比對測試時,app 截一張當下的搜尋範圍、照該找圖目標的限定範圍查一次,匹配多於一個就警告並列出每個匹配的位置;設了「第 N 個」「最接近」挑選規則的目標跳過;畫面上找不到該圖時沉默。使用者因此知道哪張圖不能當參考點。

規格:`.scratch/scale-range/spec.md`「拾取檢查」一節、user stories 12–15。接縫:拾取檢查模組單元測試、編輯器對話框測試(前例 `test_fixed_rect_ui.py`、`test_template_picker.py` 的 `_Driver`)。

**Blocked by:** 03 — 拾取檢查模組與矩形餘裕

**Status:** done

- [x] 模組的唯一:找圖目標有「第 N 個」「最接近」挑選規則就跳過;否則照限定範圍以當下倍率查一次,匹配數 > 1 警告並列出位置;匹配數 0 或 1 不警告。比色照目標設定帶進查詢(比色不符的不算匹配)。
