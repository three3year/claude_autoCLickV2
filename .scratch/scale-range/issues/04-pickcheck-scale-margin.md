# 04 — 拾取檢查:縮放餘裕

**What to build:** 截完一張範本(主視窗「截圖框選」與選範本對話框「截圖新增」兩個入口)後,app 用拾取當下的整張截圖縮到 ×0.85、放大到 ×1.15 各找一次,貼門檻就在執行紀錄區警告並在範本面板標記;比對測試也套同一檢查。使用者在建範本當下就知道這張圖縮放後行不行。

規格:`.scratch/scale-range/spec.md`「拾取檢查」一節、user stories 5–8、15。接縫:拾取檢查模組單元測試、編輯器測試(前例 `test_editor_scale.py` 的假偵測器與拾取樁、`test_template_panel.py`)。

**Blocked by:** 03 — 拾取檢查模組與矩形餘裕

**Status:** done

- [x] 模組的縮放餘裕:把截圖等比縮到(當下倍率×0.85)與(當下倍率×1.15),各以對應的預期尺度查一次,限定範圍照目標設定裁(沒有就整個搜尋範圍);找不到、或粗篩最高分 < 0.7、或驗證最高分 < 0.85 就警告,寫明哪一關、分數與倍率。單元測試驗它真的以兩個預期尺度各查了一次。

- [x] 比對測試對選中的範本同樣跑縮放餘裕,結果與現有的比對測試輸出一起顯示。
