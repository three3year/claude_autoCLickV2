# 05 — 編輯器支援外部步驟

**What to build:** 在 app 的新增列可以直接加入外部步驟。編輯窗有工具名稱、參數、備註三欄：
- 工具名稱是下拉，選項來自這份流程的登錄，也可以直接打字。
- 參數是多行文字框，一行一個參數。

步驟清單寫成「<工具名>」（標籤已寫明是外部步驟），參數有內容時接在後面（2026-11-03 使用者改：標籤已有種類名，內文不重複）。外部步驟跟其他動作步驟一樣，可以搬移、刪除、複製，可以放進重複區段，但不能當分支開頭。存檔不會動到登錄檔。詳見[規格](../spec.md)「編輯器支援到什麼程度？」。
