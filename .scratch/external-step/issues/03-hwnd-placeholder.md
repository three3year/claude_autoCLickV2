# 03 — `{hwnd}` 代入遊戲視窗

**What to build:** 外部步驟的參數寫 `{hwnd}` 時，點擊程式會代入`搜尋範圍`中心點所在的頂層視窗 handle（十進位），讓工具知道要操作哪個遊戲視窗。兩個客戶端同時開著也不會給錯。詢問預期時間與正式執行都用代入後的參數。詳見[規格](../spec.md)「遊戲視窗怎麼交給工具？」。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 參數含 `{hwnd}` → 詢問與正式執行收到同一個十進位 handle（runner 測試，視窗查詢換成假的）
- [x] 參數不含 `{hwnd}` → 不查視窗
- [x] 中心點找不到視窗 → failed，訊息寫明原因，沒有啟動工具
- [x] 一個佔位符出現在參數的一部分（例如 `--hwnd={hwnd}`）也能代入
- [x] 真的查視窗那一層，用一個實際開著的視窗驗證：給它的中心點，拿回它自己的頂層 handle
- [x] app 測試全綠
