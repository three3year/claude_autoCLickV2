# 04 — 開始前檢查與 flow_check

**What to build:** 按開始執行或測試選取時，如果流程引用的外部工具沒登錄、登錄的資料夾或入口檔不存在、或登錄檔格式錯，就跳警告，不開始執行。警告用跟範本缺圖一樣的方式，列出每個工具缺了什麼。`flow_check` 也檢查外部步驟的寫法與工具有沒有登錄，手改或工具產生的流程能事先抓到錯。詳見[規格](../spec.md)「工具沒登錄或找不到時，什麼時候發現？」。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 開始執行：四種缺漏各自擋下，警告內容含工具名與缺了什麼；沒有缺漏時照常開始（app Tk 測試，隱藏桌面）
- [x] 測試選取：選到的步驟含有問題的外部步驟時一樣擋下；沒選到時不擋
- [x] 流程沒有外部步驟時，沒有登錄檔也照常開始
- [x] `flow_check`：鍵錯、`args` 不是字串清單、工具名沒登錄 → 錯誤，結束碼 1；登錄的資料夾或入口檔不存在 → 只是警告
- [x] flow.yaml 格式規範的檢查指令段，寫明 flow_check 對外部步驟檢查什麼
- [x] app 與 tools 測試全綠
