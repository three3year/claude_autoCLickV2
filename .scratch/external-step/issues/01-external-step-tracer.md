# 01 — 外部步驟走通

**What to build:** 在 `flow.yaml` 寫一個`外部步驟`、在流程資料夾放一份`外部工具登錄`，用 app 執行時，點擊程式會先問工具的`預期時間`，再正式啟動工具並等它結束。結束碼 0 就繼續下一步，非 0 就整次失敗。結束碼和輸出的最後 5 行會進執行紀錄。詳見[規格](../spec.md)與[串接介面](../../../docs/external-step-api.md)第 1–3 步。

本票只做成功與失敗兩條路。逾時與急停在 02，`{hwnd}` 在 03，開始前檢查在 04，編輯器在 05。這段期間，登錄檔缺漏或工具找不到時，就在執行到那一步時失敗，訊息要寫明原因。

**Blocked by:** None — can start immediately.
