# 02 — 執行器記下每次的結果與原因

**What to build:** 執行器每次 `start` 都重設結果，結束時記下這一次的結果種類（完成／停止／錯誤）和錯誤原因。錯誤原因就是執行紀錄 `執行錯誤: …` 冒號後面那段文字。現在的結果欄位只在結束時設定、從不重設，也沒有原因，app 也不讀它。串接之後靠這個判斷一份流程的成敗。單獨執行看起來沒有差別。詳見[規格](../spec.md)「執行器」。

這是準備用的重構，本票不碰串接。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 用既有的 harness（真的執行器加上假的時鐘、畫面、辨識、輸入）測：
  - 一次因找不到圖而錯誤結束後再 `start`，正常完成時，結果是完成，而且沒有殘留的錯誤原因。
  - 錯誤結束時，原因等於執行紀錄那行冒號後的文字。
  - 開頭校準失敗、倍率出界都是錯誤，原因與紀錄一致。
  - 停止時結果是停止，沒有錯誤原因。
- [x] 執行中讀到的結果是「還沒結束」，不是上一次的結果。
- [x] 執行器其他行為與既有測試不變；app 全套 pytest 綠。
