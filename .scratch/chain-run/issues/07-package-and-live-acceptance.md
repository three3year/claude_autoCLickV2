# 07 — 打包與實機驗收

**What to build:** agent 重新打包。使用者在打包版上：

- 為四份在用流程設好目標程式。
- 建好「早班」「晚班」串接檔。
- 用兩個真的客戶端跑一次串接，確認輪到簡中時簡中遊戲會被移到最上層並跑完，總結正確。

詳見[規格](../spec.md)「Testing Decisions」的實機驗收。

**Blocked by:** 06

**Status:** ready-for-human

agent 的部分：

- [ ] 照 app/CLAUDE.md 的打包流程重新打包，打包前確認沒有 AutoClick 程序在跑。
- [ ] 冒煙：在隱藏桌面開打包版，日誌有 `engine.load.done`，主視窗看得到「串接…」與「執行串接」。冒煙前先查使用者在不在。

使用者的部分：

- [ ] 在「流程設定…」為早_繁中、晚_繁中選繁中遊戲，為早_簡中、晚_簡中選簡中遊戲（`Arknights_TC` 與 `Arknights bilibili` 兩個路徑），按「測試」確認選對。四份都存檔。
- [ ] 在「串接…」建「早班」（早_繁中 → 早_簡中）與「晚班」（晚_繁中 → 晚_簡中）。
- [ ] 兩個遊戲都開著，跑一次早班串接：繁中跑完後，簡中被移到最上層並跑完，總結兩行都是完成。
- [ ] 關掉其中一個遊戲再按「執行串接」：準備檢查擋下，並寫明是哪一份的目標程式沒在執行。
