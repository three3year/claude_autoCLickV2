# 01 — 抽出「執行前會擋」的檢查

**What to build:** 主視窗按「執行」前會擋下的那串檢查，改由 `flowcheck` 的一個函式提供。這個函式的輸入是一份流程的內容、它有哪些範本圖、它的外部工具登錄，輸出依現在的檢查順序排好的問題清單，每項帶類別，以及現在警告視窗的標題與文字。使用者感覺不到任何差別：單獨執行仍只跳第一個類別的警告。好處是串接的準備階段之後能對磁碟上任何一份流程列出全部問題。詳見[規格](../spec.md)「單份流程的執行前檢查抽成一個函式」。

這是準備用的重構，本票不碰串接。

**Blocked by:** None — can start immediately.
