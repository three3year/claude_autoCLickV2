# 04 — 串接檔與串接編輯對話框

**What to build:** 使用者在主視窗按「串接…」打開串接編輯對話框，建立具名的`串接檔`（例如「早班」＝早_繁中 → 早_簡中），可以從流程存放區加入流程、排序、設每份的輪數，存成流程存放區頂層的 `<名稱>.chain.yaml`。有問題的列標 ⚠，只提示、不擋存檔。本票還不能執行串接，那是 05。詳見[規格](../spec.md)「串接檔」「串接編輯對話框」、User Stories 17–28。

**Blocked by:** 03（⚠「未設目標程式」要讀 `program:`）

**Status:** done

- [x] 串接檔格式：
  - 內容是 `format: 1` 加上 `flows:` 清單；每項有 `flow:`（流程存放區裡的資料夾名稱），`run:` 選填，是正整數，沒寫＝1。
  - 讀檔時擋下：`run: forever`、非正整數、未知的鍵、沒有 `flow:` 的項目。
  - 存檔時 `run` 等於 1 就不寫出。
  - 讀寫與驗證只經 `flowfile`。
- [x] `flowfile` 能做三件事：
  - 列出流程存放區的串接檔。
  - 新增、改名、刪除串接檔。名稱不能當檔名或已有同名串接檔就擋下。
  - 列出可加入的流程時，沿用既有列出流程資料夾的函式，`*.chain.yaml` 不會出現在清單裡。
- [x] 格式規範加一節獨立的「串接檔」：
  - 表頭不能跟 `flow.yaml` 欄位表相同，因為既有一致性測試只讀第一張「適用／鍵／沒寫＝」表。
  - 寫明項目的 `run` 跟 `flow.yaml` 頂層 `run` 規則不同（不能 `forever`）。
  - 另加一個測試，確保文件列的串接檔鍵與 `flowfile` 一致。
- [x] `flowfile` 測試涵蓋：
  - 讀寫來回不變。
  - 沒寫輪數＝1、存檔不寫出。
  - 各種擋下的情況。
  - 列出串接檔。
  - `*.chain.yaml` 不在可加入的流程清單裡。
- [x] 主視窗加「串接…」鈕，打開串接編輯對話框：
  - 上方：串接檔下拉選單，加上「新增／改名／刪除」。
  - 中間：清單，每列一份流程，顯示流程名、輪數、⚠ 與文字。⚠ 有三種：「未設目標程式」「讀不到流程」「流程不在存放區」。
  - 操作：「加入…」從流程存放區的流程清單選一份，清單裡也有同樣的 ⚠；移除、上移、下移；選中的列可以改輪數（正整數）。
  - 同一份流程可以加入不只一次。
  - 底下：存檔、關閉。關閉或切換串接檔時，有未存檔改動就問。
  - 編輯串接不會改到任何流程。
- [x] UI 測試（隱藏桌面）涵蓋：
  - 新增、改名、刪除串接檔。
  - 加入、移除、排序。
  - 改輪數。
  - 三種 ⚠ 標示。
  - 存檔後的檔案內容。
  - 未存檔提問。
- [x] app 全套 pytest 綠。
