# 07 — 引擎刪多張圖登錄路徑

**What to build:** 引擎只剩單張範本：刪多張圖對齊與穩定度遮罩，遮罩只剩單張梯度啟發式（粗篩、DINOv2 驗證、比色不動）。載入範本清單只接受「範本名 → 一個圖檔路徑」，給清單就報錯；引擎參數的遮罩策略鍵退場，交付了就報錯。綁舊集真實影格的引擎測試改用新集對應案例。刪完重跑新集，結果跟基線一致。見 [spec](../spec.md)「Implementation Decisions」的引擎刪多張圖登錄路徑與測試改指兩段（ADR 0016 決策 1）。

**Blocked by:** 06 — 建立基線

**Status:** ready-for-agent

- [ ] 一個範本給多張圖路徑 → 報錯；引擎參數帶遮罩策略鍵 → 報錯（引擎公開介面測試）
- [ ] 單張圖範本照常登錄、查詢；現有遮罩與步行骨架測試只刪多張圖部分
- [ ] 舊快取比對資訊少了遮罩策略後失效、重建一次；app 讀取流程的背景預載照常完成（app 測試綠）
- [ ] 「同款多個／小圖示不被雜訊峰擠出」「比色只剩真正目標」兩組改用新集對應類型的案例、仍綠
- [ ] 只測舊多張圖素材的 profile 測試在本票刪掉（它測的就是被刪的路徑）；舊集與 `profiles/` 本身留到 08
- [ ] 重跑新集：跟 06 基線一致（已知失敗可以變少，不能變多）
- [ ] 全套測試綠（app 全套照 memory 在隱藏桌面跑，或先確認使用者不在玩遊戲）
