  → 第 46–49 步「解鎖線索」→ 第 50 步重開線索面板 → 第 51 步「傳遞線索」(右上第三顆) …
  中間的「接收線索／好友線索」完全沒出現；存檔裡也沒有這張範本（範本清單只有每日線索、傳遞線索、
  線索面板、線索交流彈窗、解鎖線索…）。
- 日誌（`app/dist/AutoClick/autoclick.log` 第 484–487 行）也只看到右上第一顆與第三顆：
  `step=43 每日線索 (1796,232,48,54)` → `step=44 領取` → `step=45 快速置入` …
  `step=51 傳遞線索 (1790,464,58,58)`（第 491 行）。中間那顆約在 (1820,375)。

  （那天沒有好友線索）——`示範影片只示範這一次`，影片沒做的事流程就不會有。

### 修正（插在 `早_繁中` 第 44 步「領取」之後、第 45 步「快速置入」之前——先收好友線索才放得進線索板）

```
44a branch_start
44b find_click 接收線索   action=click  limit=九宮格[3,6]（右上＋右中；按鈕約在 y 347–403，跨在第一、二列交界附近）  timeout=3  onNotFound=skip
                          confirm=appear  confirmTarget=全部收取（找不到＝面板沒開，依補做規則重點）
44c find_click 全部收取   action=click  colorCheck=true（只認可按的顏色；沒有好友線索時若是灰的就不按）
                          confirm=gone  timeout=5  onNotFound=break
44d （關閉收取面板：做法待確認，見下面的問題；簡中是點面板外空白處，
      改成座標點擊時加「生效確認＝確認圖出現」，確認圖用線索板上一定看得到的「傳遞線索」）
44e branch_end
```

- 範本「接收線索」可以從 demo2 f1030 直接裁（影片與 `早_繁中` 同尺度，倍率 1，約框 (1792,347,56,56)；
  影片中無紅點，範本裁的時候不要帶紅點位置，否則有紅點時反而比不到——或者反過來，若只想在有紅點時才點，
  就刻意帶紅點並開比色，看使用者偏好）。
- 「全部收取」和關閉方式影片裡沒有，**需要繁中版實際畫面**（簡中的「全部收取」範本是另一個流程尺度，
  1650 vs 1868，不建議搬）。
- `早_繁中.md` 的「流程內容」第 4 點與步驟表跟著改；改 dist 前先備份，使用者在跑流程時不要動。

### 需要使用者回答
