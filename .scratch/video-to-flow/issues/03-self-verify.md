# 03 — 自我驗證與待重拍

**What to build:** 組裝在寫存檔前,用引擎公開 API 把計畫的範本登錄成`範本清單`,對每張範本在指定影格上查詢:「該找得到的幀」要匹配且中心落在預期位置附近、「該找不到的幀」(可選)要不匹配。驗證沒過、或計畫標示找不到乾淨影格的範本,名稱加`待重拍`前綴並同步改寫步驟引用,範本與步驟仍照建;交付報告列出每張待重拍範本的原因。搜尋區域就是整張影格。見 spec「組裝 → 自我驗證」。

**Blocked by:** 01 — 組裝骨架

**Status:** resolved

- [x] 測試用真引擎(比照引擎端以合成影像跑真引擎的既有測試做法)
- [x] 框在清楚按鈕上的範本 → 驗證通過、名稱不變
- [x] 框到空白處/在該找得到的幀找不到的範本 → 名稱帶待重拍前綴,步驟引用(含`確認圖`)同步改寫,存檔內圖片名一致
- [x] 在「該找不到的幀」也匹配到的範本 → 標待重拍,原因寫「出現前就匹配」
- [x] 找到但中心偏離預期位置過遠 → 標待重拍,原因寫「位置不符」
- [x] 計畫標示無乾淨影格的範本 → 不論驗證結果都標待重拍
- [x] 只能粗篩(深度驗證模型不可用)時,報告與命令列輸出明說驗證不完整,不靜靜放行
- [x] 驗證結果(每張範本在參考幀實際找到的框)可供後續原點推算使用
