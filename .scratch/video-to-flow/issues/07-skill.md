# 07 — video-to-flow 專案 skill

**What to build:** 一個專案 skill(`video-to-flow`),讓任何 session 的 Claude 收到`示範影片`時照同一套程序把它變成流程存檔:前置檢查(profile 草稿有`搜尋範圍`、影片可讀)→ 掃描 → 覆核候選(看縮圖、剔誤報、補漏抓)→ 判斷每次點擊的語意(找圖為主、座標為輔)→ 為每張範本挑乾淨影格、用按鈕上的中文命名、同按鈕共用範本 → 明顯重複收成`重複區段` → 插入使用者口頭補充的按鍵 → 寫`轉換計畫` → 組裝 → 讀驗證結果能修則修重組、修不了留`待重拍` → 交付存檔路徑與報告摘要。不推測影片沒出現的分岔、不產出絕對座標、全程不動真實螢幕與輸入。見 spec「skill 程序」。

**Blocked by:** 01、02、03、04、05、06
