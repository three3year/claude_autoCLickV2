# 06 — 掃描:示範影片 → 候選點擊

**What to build:** 「影片轉流程」工具的**掃描**入口:讀`示範影片`偵測`點擊特效`,輸出候選點擊清單(影格編號/時間、影片像素位置、信心、可分辨時的種類:點擊/拖曳起訖)與每個候選前後數幀的縮圖,讓 Claude 不必逐幀看影片。特效長相可由一份「特效樣本」描述;沒有樣本時退回以「局部短暫劇烈變化」偵測,寧可多報。可從命令列呼叫,也可被測試直接呼叫。見 spec「掃描」。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 測試在暫存目錄用 OpenCV 合成影片(假按鈕、假游標、在指定幀畫假點擊特效),只打掃描入口
- [x] 有特效樣本時:N 次特效 → 候選含這 N 個時間與位置(容許誤差),沒有多出高信心候選
