# 01 — 組裝骨架:轉換計畫 → 開得起來的流程存檔

**What to build:** 「影片轉流程」工具的**組裝**入口走通最窄的一條路。給一份最小的`轉換計畫`(示範影片路徑、目標 profile、幾個找圖步驟、每張範本取自哪一幀與影片像素裁切框)與一個步驟草稿裡有`搜尋範圍`、且搜尋範圍與影片同尺寸(`影片換算比`=1)的 profile,工具從指定影格原尺寸裁出範本、寫出一份 app 能直接開的流程存檔放進 profile 的流程目錄,旁邊附一份骨架`交付報告`。可從命令列呼叫,也可被測試直接呼叫。見 spec「組裝」「寫存檔」「交付報告」。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 測試在暫存目錄用 OpenCV 合成小影片(有紋理的假按鈕)與合成 profile(含步驟草稿的搜尋範圍)當輸入,只打組裝入口
- [x] 產出存檔能被 app 既有的存檔讀取正常開啟:步驟與計畫一致、範本 PNG 尺寸等於裁切框、內容取自指定影格
- [x] 存檔帶上草稿的搜尋範圍作為流程層級設定;不寫校準資料
- [x] 存檔經 app 既有的流程存檔寫入產生(格式標記齊全),不另寫 zip
- [x] 目標檔名已存在 → 依 app 既有不撞名規則另取檔名,原檔內容不變
- [x] profile 草稿沒有搜尋範圍 → 報錯(提示先在 app 框搜尋範圍),流程目錄沒有新檔
- [x] 組裝失敗不留下半成品;可重跑
- [x] profile 其他既有資料(草稿、校準、其他存檔、工作區)一律不動
- [x] 交付報告(Markdown)至少列出搜尋範圍、影片換算比、步驟數、範本數
- [x] 命令列入口可指定計畫檔
