# ADR 0016：基準測試集改單張範本、從在用流程與示範影片影格重製；引擎刪多張圖登錄路徑

Status: accepted（2026-10-10）。修訂 ADR 0001 的「跨拍攝像素穩定度生成遮罩」與
ADR 0006 的「引擎 multi_capture 能力保留」。

## 背景

ADR 0006 讓 app 一範本一張圖之後，引擎的多張圖登錄（`mask_strategy: multi_capture`、
跨拍攝對齊）只剩基準測試集的素材在走。基準集 52 個案例的範本來自舊範本集
（cn／翻新），與現在真正在跑的四份流程的範本脫節——量到的是兩個月前的東西。
使用者決定不動 torch／DINOv2 驗證，但要把這條沒人用的多張圖路徑收掉。

## 決策

1. **引擎刪多張圖登錄路徑**：`multi_capture` 策略、跨拍攝對齊、`mask_strategy` 參數退場；
   遮罩只剩單張梯度啟發式（ADR 0006 已實測在單張下基準集不退步）。粗篩、DINOv2 驗證、
   比色三關不動。
2. **基準測試集從在用流程重製**：範本圖取自四份流程的 `templates/`；畫面截圖取自
   `示範影片`的影格（流程本來就是從這些影片轉出來的，影格裡有每張範本出現的畫面與
   位置）；正確位置由影片轉流程的規劃與驗證給出、人工審核。依案例類型挑影格：
   同款多個、比色、忙碌指示、縮放兩端、負樣本。每個 case 仍自帶範本圖與答案，
   加 case 仍是丟檔案不改程式。
3. 基準集住在 repo 根目錄 `benchmark/`（ADR 0015），建構工具改讀新來源。
   舊 `profiles/arknights/benchmark/` 連同其來源截圖一起刪除。

## 取捨與已知代價

- **舊案例消失。** YOLO 與特徵點時期留下的失敗案例是當初選兩階段管線的證據；
  以後只剩 ADR 0001 的文字紀錄。
- **單張遮罩對可變區的長尾較弱**（ADR 0006 已記）；真的遇到再議，不是回頭開多張圖。
- **基準集品質取決於影格挑選。** 影格不是乾淨截圖（可能有游標、點擊特效），挑的時候要避開。

## 替代方案

- **只搬位置、內容不動。** 拒絕：範本與在用流程脫節，量不到現在真正跑的東西。
- **刪掉基準集。** 拒絕：失去引擎品質的唯一客觀驗收；日後調門檻、換模型沒有依據。
- **使用者在兩個客戶端重截一輪畫面。** 拒絕：影格已經有，不必開遊戲。
