# ADR 0014：流程＝資料夾（flow.yaml＋templates/＋.cache/），取代 ADR 0006 的單一 zip；步驟選項依使用統計裁減

Status: accepted（2026-10-10）。取代 ADR 0006 的「存檔容器」部分（zip、工作區、步驟草稿）；
ADR 0006 的「引擎改收範本清單」部分不變。

## 背景

ADR 0006 選 zip 是為了「複製一個檔案就搬完」。兩個月後流程的主要產生方式變了：
四份在用流程全部由 agent 用`影片轉流程`產出，之後的修補也多半由 agent 做。zip 裡的
JSON 對 agent 是不透明的——每改一步都要解壓、改、重包，不能 diff、不能用文字工具
檢查，使用者在檔案總管也看不到圖。使用者這次明確要求：存檔要「更適合 agent 製造」，
同時仍要能方便複製到只有執行端程式的電腦。

另外對 617 步的在用流程做了一次使用統計，好幾個步驟選項從未用過（詳見決策 4）。

## 決策

1. **一份流程＝一個資料夾**：
   ```
   <流程名>/
     flow.yaml        步驟、流程層級設定（執行輪數、搜尋範圍）、校準對與基準距離、
                      備用校準對、忙碌指示、每張範本的拍攝位置、可選的引擎參數覆蓋（ADR 0015）
     templates/*.png  這份流程引用到的每一張範本圖；檔名即範本名
     .cache/          可重建：引擎登錄產物（參考圖、遮罩、向量、meta）與未存檔的暫存截圖
   ```
   複製整個資料夾就搬完；`.cache/` 跟著走，到新電腦不必等預載。缺圖時開檔明確報錯。
2. **欄位用自述性英文名、預設值不寫出來**（例：`find_click` → `find`，`mode: prev` 整個
   欄位消失）。找圖「找不到時」沒寫＝停止（原本執行器預設跳過、影片轉流程預設停止，統一為停止）。
3. **存檔語意**：改動留在記憶體，按存檔才寫 `flow.yaml`；關閉時提示未存檔；開啟 app 讀上次
   開的流程，不再有`步驟草稿`；新流程在第一次存檔時才選資料夾；未存檔的截圖先放 `.cache/`，
   重開 app 或讀取流程時清掉。**存檔只寫被引用的範本**——被移除步驟的圖一併移除，
   `templates/` 永遠等於引用集合。`工作區`退場：圖本來就在磁碟上，不再需要解壓。
4. **從格式與 UI 一起拿掉**（四份在用流程 617 步、337 個找圖的統計）：
   - 按鍵步驟（0 次；影片也看不到按鍵）
   - 絕對座標模式（座標點擊 77 步全部相對原點）、滑鼠鍵、連點數（全部左鍵單擊）
   - 以原點為基準的限定矩形（10/10 版 0 次；固定矩形 331 次）
   - 出現等候上限（0 次；用途已被忙碌檢查取代，ADR 0011）
   - 補做間隔、忙碌出現等候（從未改過 1000ms）→ 改成程式常數
   - 啟動延遲、避開游標（四份流程都是 3 秒、都開）→ 固定 3 秒、一律開
   保留：找圖三態、生效確認四選一、找不到時三選一、挑選規則四種、固定矩形、比色、
   忙碌檢查、更新原點、點擊偏移、重複與分岔、兩種區段結束的跳出後動作（巢狀重複
   「內層失敗要連外層一起跳出」只有它能表達）。
5. **搜尋範圍照舊存在流程裡**（螢幕座標）。換電腦時它是舊電腦的矩形：校準失敗就提示重框，
   一次即可。agent 寫流程可留空＝全螢幕。
6. **一次性轉換工具**：輸入是打包版裡 2026-10-10 的四份 `.autoclickpack`（早_簡中、早_繁中、
   晚_簡中、晚_繁中），跑完即功成身退；舊格式與其讀取碼全部刪除。

## 取捨與已知代價

- **放棄「一個檔案」。** 複製要整個資料夾一起；使用者判斷資料夾已經夠方便。
- **改錯沒得反悔。** 沒有草稿與自動存檔；靠明確存檔與 git／複製資料夾。
- **拿掉的選項加回來要改格式。** 滑鼠鍵、按鍵這類執行器底層仍支援的東西，加回來約一小時；
  使用者接受。
- **轉換只顧四份流程。** 其他舊存檔（profiles/ 裡 8 月的 format 2）不轉、不再能開。

## 替代方案

- **zip 裡的 JSON 換 YAML。** 拒絕：agent 每次改仍要解壓重包，問題沒解。
- **資料夾為主、另給「包成 zip」。** 拒絕：第二條載入路徑，與精簡目標相衝；複製資料夾已夠。
- **保留自動存檔草稿。** 拒絕：使用者要的是明確存檔語意（改動暫存、按存檔才落地、關閉提示）。
- **格式保留選填的滑鼠鍵、出現等候上限等，只藏 UI。** 拒絕：使用者選擇格式與 UI 一起拿掉，
  執行器少幾條路徑。
