# app UI 慣例（已拍板的決策，不要改回去）

改版面、樣式、色票、對話框或清單的互動前讀這份。這裡每一條都是和使用者定過的設計；
要改先問，不要「順手改好」。

## 樣式與色票

- 色票：背景 #0F172A、面板 #1E293B、hover 統一 `ui_theme.HOVER`(#31405A)、執行綠 #22C55E；
  截圖選取層所有線條（吸附框／拖曳框／拉線／提示框）統一藍 #2080F0。
- 步驟標籤［…］顏色：找圖=info、座標點擊=accent、拖曳=#A78BFA、等待=muted（`LABEL_COLORS`），
  重複／分岔標記沿用整列顏色。
- 次要小按鈕用 `Small.TButton`（`width=0`，原因見坑裡的 clam 一條）。
- 說明文字一律簡化進 ⓘ 懸停顯示、⚠ 警告縮一行常駐（全部對話框適用）。

## 視窗與對話框

- 子視窗一律用 `ui_dialogs.make_modal()` 而非直接 `grab_set`（含點外閃爍提示）：它把視窗登進 modal 堆疊，
  grab 永遠在堆頂、關閉後自動回到下一層——巢狀視窗（編輯對話框＋比對測試結果）不需要也不要再手動交接 grab。
- 常駐螢幕的覆蓋框（如搜尋範圍預覽）：框線畫在範圍外側（避免拍進截圖）、用 `win.make_click_through()` 點擊穿透、
  綁 root 的 `<Map>`／`<Unmap>` 自動顯隱。
- 步驟編輯器是版面 B（`ui_dialogs._StepEditor`）：兩欄（找什麼｜找到之後；座標點擊、拖曳是位置｜送出之後），
  全攤開不折疊、寬度固定；依選項出現的列登記在 `_optional`、由 `sync` 顯示／收起；找圖選「不點擊」「等待消失」時，
  點擊偏移、生效確認與忙碌檢查整列收起、存為沒勾。兩欄寬 `CARD_W` 是量出來的（`.scratch/ui-slim/measure_editor.py`），
  加欄位或改字後要重量。
- 流程設定對話框三列（校準對、備用校準對、忙碌指示）各有設定／清除／測試；「測試」只量測並寫紀錄，不存任何值。

## 截圖選取層

- 游標吸附視窗／元件框（依 z-order、被遮蓋部分不吸附）、高亮區外壓黑（暗版底圖＋原亮度裁切圖蓋回）、
  有放大鏡、無十字準星；粗藍框只在 region 模式，point／line 拾取只有壓黑高亮。
- 拾取相對座標用拖線：起點=基準、終點=目標。
- 找圖搜尋範圍只有主視窗的全域設定，步驟不各自設範圍。

## 範本

- 範本正式名稱＝平面名稱＝檔名（沒有資料夾層級）；截圖自動命名 `tmpl_NNN`（自動產生的名字經 `flowfile.clean_name`
  清成能當檔名）；使用者改名輸入不能當檔名的字元＝擋下說明，不靜靜改寫。主視窗的範本面板列的是本流程的範本
  （平面清單），改名靠面板的重新命名（`flowfile.rename_template_refs` 同步改寫所有引用含確認圖、校準對、忙碌指示，
  撞名自動加序號）。
- **選範本一律走 `ui_dialogs.pick_template`**：左側樹狀「新加入／本流程／流程存放區底下的其他流程資料夾」
  （其他流程只列檔名，預覽才讀那一張）、可從磁碟挑 PNG、可現場截圖；**按確定才複製進本流程**，取消時檔案系統
  完全沒有變化。確認圖走同一個對話框（取消時這次加進來、最後沒被引用的圖一併丟棄）——舊的「截圖即時存檔、
  取消對話框圖仍留下」語意已經改掉，別再加回去。

## 主視窗與步驟清單

- 兩列工具列＋兩欄（步驟｜範本上、紀錄下）；未存檔只標題加 `*`；迷你視窗不動。
- 步驟標題列的新增鈕（版面 D）：找圖／點擊／拖曳／等待一排＋「區段 ▾」，標題列寬度不夠時整排換成一顆
  「＋ 新增 ▾」列出全部九項（`_build_steps` 的 `fit` 比較標題列寬度與那排鈕的需求寬度）。
- 步驟清單是 `SegListbox`（tk.Text 實作、相容 Listbox 介面，不是 Listbox）：選取只加背景不變文字色、
  │ 連線依隸屬區塊顏色（重複=warn、分岔=info）、號碼欄用 tab 定位點對齊（比例字型下位數不同會讓縮排右偏）。
- 步驟多選拖曳：把手按在已選取列上＝整組拖曳（不連續選取會併攏成連續區塊、相對順序不變），按列內文仍縮成單選；
  新增步驟插在選取列（收合區段算整段）之後，無選取才接在最後。
- 「測試選取」＝只執行清單選取片段（跳選補滿頭尾、收合算整段、一律單次），共用 `start_run(steps=…, test=True)`
  與 `_flow_error(steps)`；迷你視窗摘要對照 `_run_steps`（實際在跑的清單），不是 `self.steps`；片段內相對座標步驟
  若在任何原點來源之前，執行前即擋下（`_fragment_origin_error` → `flowcheck.no_origin`）。
